# S1 · phase-gate.py：阶段越界 deny + 起飞模型确认阻断

**目标**：把两件事从"模型自觉"变成 hook 判定——explore 阶段不许产出飞行计划工件 / 跑 baseline；起飞前人必须确认执行模型。

## owns

- `template/.claude/hooks/phase-gate.py`（新建）
- `tests/test_phase_gate.py`（骨架已在，去掉 xfail 标记即解锁）

## 事实基线（已对官方文档 + 本机 2.1.269 验真，不要再猜）

- **hook 事件能力**（`code.claude.com/docs/en/hooks` 的 "Exit code 2 behavior per event" 表）：
  - `UserPromptSubmit` exit 2 → "Blocks prompt processing and **erases the prompt**"，stderr 呈现给人。
  - `PreToolUse` → 支持 `permissionDecision: "allow" | "deny"`。
  - `SubagentStart` **不能阻断**（"Exit code 2 isn't honored"）——不要试图用它拦执行体。
- **hook 输入字段**：公共字段含 `session_id` · `transcript_path` · `cwd` · `permission_mode` · `hook_event_name`；`PreToolUse` 另有 `tool_name` · `tool_input` · `tool_use_id`；`UserPromptSubmit` 另有 `prompt`。**用 `hook_event_name` 区分两种模式**，不要靠"有没有 tool_name"猜。
- **转录形状**（与 `takeoff-gate.py` · `session-model.py` 同源）：
  - assistant 条目：`{"type":"assistant","isSidechain":false,"timestamp":"…Z","message":{"model":"claude-opus-5",…}}`；`<synthetic>` 要跳过。
  - 人类消息：`type=="user"` 且 `isMeta` 非真、`isSidechain` 非真、`userType=="external"`、内容是文本而非 `tool_result`；含 `<local-command-stdout` / `<task-notification` / `[Request interrupted by user]` / `<bash-input` / `<bash-stdout` 的不是人打的字。
  - 命令消息形如 `<command-message>opsx-explore</command-message> <command-name>/opsx-explore</command-name> <command-args>…</command-args>`。
- **已存在、不要重复实现**：`session-model.py` 提供 `alias_of(model_id) -> str | None`（按子串映射 `opus`/`sonnet`/`haiku`/`fable`，`[1m]` 变体自然归基座）；`takeoff-gate.py` 已覆盖"派实现类子 agent 需人类批准"。本切片**不改这两个文件**。

## 契约

```
python3 .claude/hooks/phase-gate.py        # 只从 stdin 收 hook JSON，无 CLI 子命令
```

### 模式 A · `hook_event_name == "PreToolUse"`

1. 从转录取**最后一条人类命令消息**里的 `/opsx-<x>` 作为当前阶段；取不到 → 静默放行。
2. 阶段 != `explore` → 静默放行。
3. 阶段 == `explore` 时判越界：
   - `tool_name` 属 `Write` / `Edit`，且 `tool_input.file_path` 命中 `openspec/changes/*/` 下的 `slices.json` · `tasks.md` · `slices/*.md` → **deny**。
   - `tool_name == "Bash"`，且 `tool_input.command` 含 `slice-gate.py` 与 `baseline` 两者 → **deny**。
   - 其余 → 静默放行（`proposal.md` · `design.md` · `specs/**` 必须放行）。
4. deny 输出（与 `intent-gate.py` 同形）：
   ```json
   {"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"deny","permissionDecisionReason":"…"}}
   ```
   reason 点名当前阶段是 explore、该动作属 propose 收口、要显式 `/opsx-propose`。

### 模式 B · `hook_event_name == "UserPromptSubmit"`

1. `prompt` 不含 `<command-name>/opsx-apply` 或 `/opsx-bulk-apply` → 静默放行（exit 0）。
2. 读转录末条主循环 assistant 的 `message.model` → 别名：
   - 转录定位不到 / 读不出 / 无 assistant 条目 → **放行**（fail-open，D5）。
   - 读得到但 id 映射不出别名 → **exit 2**，stderr 点名原始 id。
3. `prompt` 里找 `--confirm-model=<alias>`：
   - 缺失 → **exit 2**，stderr 打印：change 名 · 当前主模型别名 · 切片数与 wave 数（读 `slices.json`，读不到就省略这一项）· 两条出路，其中"就用它"一行是**可直接复制的完整命令**，并带 worktree 的**绝对路径**（从 `cwd` 向上找含 `openspec/changes/<name>` 的 worktree 根；找不到就省略路径一项，不因此失败）——人 `/clear` 之后不必自己拼目录。
   - 存在但 != 实测别名 → **exit 2**，点名 flag 声称 X 而实测 Y。
   - 一致 → 静默放行，**不写任何文件**。

### 通用

- 任何异常一律放行（与 `intent-gate.py` · `takeoff-gate.py` 同规矩）；坏行跳过不崩。
- 只读，不改任何文件。兼容 Python 3.8+，只用标准库。
- change 名从 prompt 的 `<command-args>` 取第一个非 flag token；取不到就从 `openspec/changes/` 下唯一活跃目录推断，仍不唯一则省略该字段（不要为此阻断）。
