## 做什么（design D7）

### `template/plugins/flight/hooks/resume.ts`（新建）
`resumeFlight(deps, change, { replan })` 按 `_interfaces.md` 与 spec 的步骤实现。依赖全部经 `deps` 注入，本模块不碰 `$`。
- **开头**：`deps.toast('续飞准备中…')`。
- **replan 且基线红**：通知「<change>：基线红，未续飞：<reasons 首行>」，返回该文本。
- **调用 takeoff**：参数为 `[change, '授权提交']`，opts 为 `{ resume: true }`。回复首行经 `notify` 发出。

### `template/plugins/flight/hooks/register.tsx`

**候选项的停飞态**：`evaluate` 在算完指纹后，读一次账本（`ledger.py show`）判断最新 attempt 是否以 halt 结束（最后一条 takeoff 之后有 halt、没有 land）：

| 停飞态 | 当前指纹 vs 最近批准指纹 | 结果 |
|---|---|---|
| 是 | 不等 | 返回 `{…, mode: 'replan'}` |
| 是 | 相等 | 返回 `{…, mode: 'resume'}`（现在这种情形返回 undefined，即不显示） |
| 否 | — | 行为不变（`mode: 'approve'`） |

读账本失败时按「否」处理。

**绘制**：

| mode | 按钮（key 前缀） | 说明行 |
|---|---|---|
| `approve` | 「批准起飞」（`approve:`） | — |
| `replan` | 「批准修订并续飞」（`replan:<change>:<fp>`） | `<Text dimColor>` 写「按下会提交本 change 的工件、重跑基线，续飞只重派未合回的切片」 |
| `resume` | 「续飞」（`resume:<change>:<fp>`） | — |

**按下**（`ui.press`）：
- **`replan:`**：
  1. 核对指纹（同 approve）；
  2. 走 approve 的串行段追加 approve；
  3. 不预填；
  4. `$.clock.after(0, () => void resumeFlight(depsOf($), change, { replan: true }))`。
- **`resume:`**：
  1. 核对指纹；
  2. 不写 approve；
  3. 同样后台 `resumeFlight(…, { replan: false })`。

**`depsOf($)`**：
- `takeoff`：`import { takeoff } from './orchestrator'`；
- `baseline`：经 `$.process.run` 跑 `python3 <hooksDir>/slice-gate.py baseline --change-dir <changeDir>`，cwd 为 change worktree，超时 600000；
- `stopLive`：读账本，取本 attempt role 为 diagnostician、未 ended 的 agent，`$.agent.list` 里仍 running 的，逐个 `$.tool.call({tool: 'TaskStop', task_id})`；
- `notify`：`$.ui.notify(text, {title: 'flight'})`，失败吞掉；
- `toast`：`$.ui.toast`。

### `template/plugins/flight/types/index.d.ts`
`FlightItem` 加 `mode: 'approve' | 'replan' | 'resume'`。
