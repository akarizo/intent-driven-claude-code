## 做什么（`template/plugins/flight/hooks/versions.ts`，design D1）
- **导出常量**：`REQUIRED_FEATURES = ['evidence-ledger-only', 'g5-per-target', 'guards'] as const`。
- **`checkJudges`**：在现有的 `ledger.py events` 核对通过之后，再运行 `python3 <hooksDir>/slice-gate.py features`。
  - **退出码非 0**：返回 `{ ok: false, reason: 'flight：判定器过旧（<hooksDir>/slice-gate.py 没有 features 子命令）：' + UPDATE_MAIN }`。
  - **缺少能力**：按行取能力名，缺少 `REQUIRED_FEATURES` 中的任一项，就返回 `{ ok: false, reason: 'flight：判定器（<hooksDir>）缺少能力 <缺少的，用「，」连接>：' + UPDATE_MAIN }`。
  - **都齐**：通过，同现有返回。
- **签名不变**：`checkJudges` 的参数与返回类型都不变，S4 和 orchestrator 不用改调用。
- **`UPDATE_MAIN` 文字**：`先把主检出更新到与插件同一版本`。保持不变，但它必须出现在两条新原因里。
