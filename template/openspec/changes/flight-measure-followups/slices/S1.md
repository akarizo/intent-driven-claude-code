## 做什么（只改 `template/plugins/flight/hooks/envelope.ts`，纯函数）

1. **前缀命令**：`words` 里查 `PREFIX_OPTS` 之前，先把词去掉一层引号再取 basename，例如 `t.replace(/^["']|["']$/g, '').split('/').pop()`。这样 `/usr/bin/env`、`"exec"`、`'command'` 与裸名同样识别为前缀；后面的选项、`VAR=` 剥离与 `env -C` 处理照旧。
2. **目录参数里的 shell 展开**：`resolveDir` 拿到的参数是已去一层引号的。只要其中任意位置还含 `$`、反引号、`'` 或 `"`，就返回 null。
   - 现有的 `~`、`$`、`+`、`-` 开头规则保留。
   - `cd`、`pushd`、`git -C`、`--git-dir`、`--work-tree`、`env -C` 都经过 `resolveDir`，一处改全覆盖。
3. **拒绝理由**：改动类 git 因作用目录无法判定（null）被拒时，理由里的那一段改为「作用目录无法判定（目录栈旋转、相对路径无基准、变量或命令替换等）」，不再出现「相对路径且无绝对基准」。理由前半句「…只能作用于自己的 worktree…」保留。
