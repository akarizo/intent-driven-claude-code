## 做什么（design D1、D3、D4）

### 1. `template/.claude/hooks/takeoff-gate.py`
- **删除 hook 模式**：`DISPATCH_TOOLS`（约 :30）、`TAKEOFF_AGENTS`（约 :32）、`find_change_dir` / `is_takeoff_dispatch` / `run_hook` / `emit_deny`（约 :89-137），以及头注释里关于 hook 模式的段落（约 :10-15）。
- **不带参数运行时**：读掉 stdin（读不到也不报错），不输出，退出 0。说明写「hook 模式已退役，空转兼容仍注册它的 settings」。
- **CLI 模式不变**：`--change-dir`，即 `verdict` / `run_cli` / `remedy` / `INSTALL_HINT`。插件起飞守卫在用。

### 2. `template/.claude/hooks/stop-gate.py`
整文件换成兼容空壳：
- 头部 docstring 写「已退役：旧引擎的执行体自跑门禁用；插件由控制面在收口时跑门禁。保留空壳只为兼容仍不带存在保护注册它的 settings（删除文件会让 Stop hook 报错）；新安装不再注册」；
- `main` 读掉 stdin，不输出，退出 0；
- 不 import slice-gate、不读标记。

### 3. `template/.claude/hooks/test-evidence.py`
- git toplevel 下存在 `.openspec-slice` 标记时，**一律不写**（不论标记里的 evidence 模式）。即约 :53-67 的标记分支改为直接返回。
- 没有标记时照旧（约 :71-90）。
- 头注释（约 :6-8）改为「飞行外的测试留痕（主会话修复、per-task 路径）；切片 worktree 的测试由控制面测量入账本」。

### 4. `template/.claude/hooks/hooks.json`
- **删除这些注册**：
  - PreToolUse `Workflow|Agent|Task` 的 takeoff-gate（约 :13-21）；
  - PostToolUse `Write|Edit|Bash` 的 checkpoint（约 :51-59）；
  - PostToolUseFailure `Bash` 的 checkpoint（约 :71-79）；
  - Stop 的 stop-gate（约 :81-90）；
  - SubagentStop 的 stop-gate（约 :91-100）。
- 某个事件删空了就去掉这个事件键。
- test-evidence 的两条（约 :42-50、:62-70）与其余 hook **保留**。

### 5. `template/.claude/hooks/session-decompose.py`
删除整个文件（`--expect-models` 依赖 Workflow journal；插件在 `core.ts` 的 `routingFindings` 从账本对账）。
