# S5 · 接线：orchestrator.tsx 造 Ctx，接上落地逻辑与 submit_findings

## 做什么
`template/plugins/flight/hooks/orchestrator.tsx`（3a S7 写的，先读一遍）是**唯一注册飞行 hook 的文件**，`$` 只在这里出现（实测 X12）。

1. **造 `Ctx`**：把现有的 `ioHere($)`、`spawnHere(...)` 合成 `function ctxOf($): Ctx`（`Ctx` 由 S4 加在 `core.ts`）：
   - `io`
   - `now: () => $.clock.now()`
   - `spawn: ({ f, role, cwd, prompt, description }) => $.agent.spawn({ prompt, description, subagentType: agentType(role), model: f.model, cwd })`（结果转成 `{ agentId } | { deny }`）
   - `status: t => $.ui.status(t)`
   - `toast: t => $.ui.toast(t)`
   - `runCommand: (command, args) => $.command.run({ command, args }).then(() => undefined)`
2. **落地动作**：删除空壳 `landingHere`。drive 遇到 dispatch reviewer / fixer、final、land、halt 时，调用 `runLandingAction(ctxOf($), f, a)`（从 `./landing` import）。读账本失败时的 halt 同样交给它。
3. **drive 防空转**：每轮记下读到的事件数；执行完本轮动作后，若下一轮读到的事件数没变，就停止（不再跑满 `MAX_ROUNDS`）。
4. **起飞异常**：
   - `command.run` 的 hook 内用 `try/catch` 包住 `takeoff`，异常时返回 `{ text: 'flight：起飞异常，不起飞（<异常首行>）' }`；
   - hook 再加 `.catch(($, e, next) => ({ text: 'flight：起飞异常，不起飞' }))`；
   - 两处都**不** `next(e)`。只有参数含 `--engine=workflow` / `--gate=per-task` 时才 `next(e)`。
5. **submit_findings**：
   - `session.start` 注册 `$.tool.register({ ...FINDINGS_TOOL, isDeferred: false })`。register.tsx 已有不带 matcher 的 session.start，这里要带恒真 matcher `{ cwd: /^/ }`（3a S8 实测）。
   - `tool.call`（matcher `{ tool: 'mcp__flight__submit_findings' }`）→ `onFindings(ctxOf($), await flightOfAgent(io, agentId), agentId, e)`，再加 `.catch(... => ({ deny: 'flight：评审回收失败' }))`。
6. **收口**：`classic.SubagentStop` 里，executor / resolver 的处理不变；其他 role → `const r = await onLandingStop(ctxOf($), found, agentId)`，有 `block` 就 `{ ...(await next(e)), block: r.block }`，否则 `next(e)`。
7. **收窄批准带断言**：
   - `tests/flight.test.tsx` 的 `no-model-callable-approval-path` 改为「注册的工具恰为 submit_findings、没有斜杠命令」；
   - 新增 TS 测试 `only-findings-tool-registered`：工具只有 submit_findings、无命令；主会话以各种输入调用 submit_findings，都被拒绝，账本不出现 approve 事件；
   - `tests/test_flight_plugin.py` 里 `test_no_model_callable_approval_path` 的注释同步，`test_only_findings_tool_registered` 去掉 xfail。
8. **版本**：
   - `template/plugins/flight/.claude-plugin/plugin.json` 的 version 升到 `0.2.0`；description 补一句「接管 /opsx-apply：状态机编排、收口门禁、合回、评审回收、落地接 pr-ship」；
   - `.claude-plugin/marketplace.json` 的 description 同步。
