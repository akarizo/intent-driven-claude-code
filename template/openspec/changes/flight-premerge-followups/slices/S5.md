## 做什么

### `types/index.d.ts`
1. `FlightItem` 新增可选 `defect?: string`（计划缺陷的原因首行；有值时不画主按钮），带注释。

### `register.tsx`
2. **evaluate**：停飞分支里，`same`（计划未改）且 `planDefect(reduce(<本项账本事件>))` 有值 → 返回 `{ …, mode: 'resume', problem: '', defect }`；计划改过仍为 replan，不带 defect。账本事件用已有的 `readLedger(ioOf($), f)` 结果，不另读。
3. **绘制**：顶部项有 `defect` 时：
   - 不画主按钮；
   - 画文字「计划需修订：<defect>」与一行 dim「改计划后会出现「批准修订并续飞」」；
   - 照常画「搁置」按钮与搁置说明行。
4. **按键防御**：`resume:` 键对应的项带 `defect` → toast「flight：<change> 计划需修订：<defect>」并刷新，不续飞。
5. **认领 hook**（design D8 · D1）：`.catch(($, e, next) => (next.called ? { text: … } : next(e)))` 里，`next.called` 时回复「flight：命令执行出错：<错误首行>」，错误取 `(next as unknown as { error?: { message?: string } }).error?.message`，取不到时回原文「flight：命令执行出错」。
