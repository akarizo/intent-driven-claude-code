# S3 · 工作流：抛错按未返回重派、执行体一律隔离、fix 合回后再 final；文档同步

**目标**（design D2、D3）：
- `agent()` 抛错按未返回处理并重派一次；
- 每个执行体（含单片 wave 与 fix）都隔离，由 integrator 合回；
- finalize 先合回 fix commit 再跑 final；
- 命令、同名 skill、执行体 / integrator 定义、git 纪律的例外条款同步改。
