## 做什么（design D1–D3 的执行侧、D2 接线、D5、D6、D8）

### `template/plugins/flight/hooks/orchestrator.tsx`

**`perform` 处理 `heal`**：追加 `ev.heal(b, {attempt, kind: a.heal, slice: a.slice, reason: a.reason, agent: a.agent})`，返回写入结果。重派由下一轮 `next` 给出。合回重试是「全新派发」（不带 continuation），现有逻辑会另起新 worktree，确认用例覆盖到「路径不同」。

**`ctxOf` 增加 `notify`**：
- 调 `$.ui.notify(text, { title: 'flight' })`；
- 返回 `isSent: false` 时，用 `ctx.log` 写一行「flight 通知未发出：<reason>」；
- 抛错同样记一行，不抛。

**看门狗**：
- **模块级状态**：一个 `StepTracker`（S3），外加「已处理 agent」集合。
- **`on('turn.step', { agentId: /./ }, async function* ($, e, next) { … })`**：
  - 只在 agent 属于在飞 change 时（`flyingWho` 或 owners 缓存）`start(e.agentId, now)`；
  - `try { return yield* next(e) } finally { end(e.agentId) }`；
  - 计时器未起或已结束时在这里重起（幂等）。
- **`session.start` 里起 `$.clock.every(60000, tick)`**。每次 tick 处理 `tracker.stale(now)` 里未处理过的 agent：
  1. `flightOfAgent` 找飞行，读账本；
  2. attempt 已 land / halt → TaskStop，不记 heal；
  3. `healVerdict(state, 'watchdog', key)` 允许 → 先追加 heal（agent 为它，reason 含等待分钟数），再 TaskStop；
  4. 不允许 → `runLandingAction(ctx, f, {kind: 'halt', reason: …, haltKind: 'watchdog'})`，再停本 attempt 仍在跑的全部 agent（复用 `abortCommand` 里 live / stop 的写法）。

  key 的写法见 `_interfaces.md`。
- **TaskStop 的结果**：`$.tool.call` 对已结束的 agent 返回 `{ isError: true, … }`（2.1.296 实测，不抛）。`isError` 或抛错时追加 `ev.diag(b, {attempt, where: 'watchdog', agent, error})`。
- **整段 tick 包 try/catch**，异常只记 diag，不让计时器因抛错停掉。

**停飞后派诊断员**：
- driveNow 里执行 halt 之后（`perform` 的 halt、`terminal()`、看门狗停飞），halt 的 kind 不是 abort、fingerprint 时，在 change worktree 派发诊断员：
  - `ctx.spawn` 的 role 为 diagnostician，`agentType('diagnostician') = 'flight:diagnostician'`，显式 model 为 `f.model`；
  - 提示词为 `triagePrompt({change, changeDir, hooksDir, reason, kind})`；
  - 追加 `dispatch {role: 'diagnostician', slice: 'triage', …}`。
- `HIDDEN` 加 `flight:diagnostician`。
- `turn.complete` 收到诊断员结束时：
  1. 照旧追加 ended；
  2. 从 `await next(e)` 的结果取 `text`，截断 4000 字，空则「（无回答）」；
  3. 追加 `ev.triage`；
  4. `ctx.notify` 首行；
  5. 刷新面板。

  此时不必 drive（attempt 已结束）。

**halt 分类的执行侧**：
- `terminal()` 的 halt 带 `haltKind: 'control'`；
- `abortCommand` 的 halt 带 `haltKind: 'abort'`。

**`takeoff` 改为 `export`**（签名不变），供 S6 的 resume 使用。

**包络角色**：`envelopeOf` / owners 对 diagnostician 的 owns 为空（与 reviewer 同），`inEnvelope` 不为它升 allow。
