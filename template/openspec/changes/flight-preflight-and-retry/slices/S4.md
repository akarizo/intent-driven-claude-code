## 契约

- **pr-ship.md step 10**：开头改为「有 CRITICAL/HIGH → 唯一一次 **AskUserQuestion**：『自动修并 push』/『只贴评论交人』；无人应答默认只贴评论。选自动修 → 原有流程（至多 2 轮）；否则只贴评论、`review-findings.json.blocking` 保留、`ship` 照常裁 draft」。**step 11** 删掉「可选一次 AskUserQuestion」，改为直接结束并给 merge 命令。**Guardrails** 改为「全程至多问询 1 次（仅 step 10 自动修复前）」。全文 `AskUserQuestion` 恰好 1 处。
- **opsx-propose.md / SKILL.md step 4**：说明 baseline 现在还跑 lint / typecheck 基线与每片 verify，产出 `gate-baseline.json`；「退出非 0 → **停下报告** stdout 的 `reasons`，不渲染、不交接；人类修 `gate.test` / `verify` / 环境后重跑本步」；一句「verify 在基线上必须绿（骨架是 strict-xfail）」。两份同句。
- **schema.yaml Slicing rules** 加一条：`verify` 只跑测试——禁含 typecheck / lint 工具（`tsc` / `typecheck` / `eslint` / `rustfmt` / `clippy` / `ruff` / `mypy` / `flake8` / `golangci`）；typecheck 放 `gate.typecheck`、lint 放 `gate.lint`，门禁按基线差分排除既有错误（由 `slice-gate.py lint` 校验）。改完 `cd template && openspec schema validate intent-driven` 必须绿。
