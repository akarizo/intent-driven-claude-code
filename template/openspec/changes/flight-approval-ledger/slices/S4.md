## 契约

```text
verdict(change_dir) -> (ok, evidence, reason)
  fp = plan_fp.plan_fingerprint(change_dir)          PlanError → (False, "", "无计划工件…")
  event, tip = ledger.latest_approval(change_dir)     LedgerInvalid → (False, "", "账本损坏：<sha8> <原因>…")
  event 为 None → 「未批准」；event.fp != fp → 「计划已变，需重新批准（批准的是 <旧8>，当前是 <新8>）」
  ok → evidence = "<event.at> · fp <fp8> · ledger <tip8>"
  每条拒绝理由都附：spec.html 绝对路径 · 「在 Claude Code 输入框上方的批准带按『批准起飞』」·
    「未安装插件：claude plugin marketplace add akarizo/intent-driven-claude-code --scope project && claude plugin install flight@intent-driven -s project」
CLI   --change-dir DIR（移除 --session）：ok → exit 0、stdout=evidence；否则 exit 3、stderr=reason
hook  沿用 is_takeoff_dispatch + find_change_dir；不成立 → emit_deny；载荷里的 transcript_path 不读
fail  「没有批准」「非 git 仓库」「无引用」= 判定结果 → 拒绝；git 不可执行（FileNotFoundError）/ 脚本异常 = 门禁故障 → hook 放行、CLI exit 3 并说明
```
