**目标**：新增只读判定器 `ledger.py`，读取并校验 `refs/flight/<change>/ledger` 提交链（design D2 / D3）。**不提供任何写入子命令**（写入只在 S3 插件进程内）。

**deps: -**（wave 1；S4 import 本片的 `latest_approval`，S3 按 CLI 契约调用 `approved`）

## 事实基线

- 测试基座 `tests/conftest.py` 新增：`ledger_append(repo, change, event=None, *, files=None, parents=None, ref=None)` 用 git plumbing 造合法 / 非法提交；`approve_event(change, fp, at=…)` 生成 v1 事件；`make_change`。
- refs 在 git 公共目录：worktree 内 `git -C <change_dir>` 读到的就是主仓库的 `refs/flight/*`（测试 `test_ledger_shared_across_worktrees`）。
- 兼容 Python 3.8+，只用标准库。

## 契约

```text
ledger.py
  ref_for(change) = "refs/flight/%s/ledger" % change
  class LedgerInvalid(Exception): sha8, reason
  read_events(change_dir) -> list[dict]          按写入顺序；无引用 → []
    · change = basename(normpath(change_dir))；repo = git -C change_dir
    · git rev-parse -q --verify <ref>：不存在 → []
    · git rev-list --reverse --parents <ref>：任一提交父提交数 > 1 → LedgerInvalid
    · 每个提交 git ls-tree：必须恰一项、名为 event.json、类型 blob
    · git cat-file -p <blob> → json.loads：非 JSON / 非对象 → LedgerInvalid
    · 字段：v == 1；ev ∈ {"approve"}；change == 目录名；fp 匹配 ^[0-9a-f]{64}$；at 为字符串；by 为含 plugin 的对象
  latest_approval(change_dir) -> (event | None, tip_sha | None)
CLI：ledger.py {show|approved|verify} --change-dir DIR
  show      每行一个事件 JSON（ensure_ascii=False），按顺序；无账本 → 空、exit 0
  approved  最新 approve 的 fp；无 → 空、exit 0
  verify    合法 → exit 0
  LedgerInvalid → exit 4，stderr 一行「账本损坏：<sha8> <原因>」
  其他异常（git 不可用等）→ exit 5，stderr 一行原因
```

## 坑

- ⚠ 只读：不得出现 `update-ref` / `commit-tree` / `hash-object -w` 等写命令（S3 的 Bash 守卫与 ADR 都以此为前提）。
- ⚠ `--change-dir` 指向的目录可以不存在于当前工作区以外的地方，但必须在某个 git 仓库内；不读环境变量、不猜仓库位置。
- ⚠ 校验对全链生效：链上任一提交非法即整本判坏（不做部分信任）。
- ⚠ 每条测试解锁时去掉 `@XF` 标记。
