# S3 · io.ts：agent 归属的「登记中」状态与未命中缓存

## 做什么
`template/plugins/flight/hooks/io.ts`（设计 D6）：
1. **`pending`**：新增 `pending: Map<agentId, change>` 与 `export function markPending(agentId: string, change: string): void`。
2. **归属查询的返回类型**：`Owner | { pending: true; change: string } | undefined`。为免牵动现有调用点，新增 `export async function ownership(io, agentId)` 返回这三态，`ownerOf` 保持原签名：登记中时返回 undefined。S4 接线时改用 `ownership`。
3. **dispatch 写入**：`remember` 处理 dispatch 事件时，除写 `owners` 外，还要 `pending.delete(agentId)`，并清空 `misses`。
4. **`misses`**：新增 `misses: Set<string>`。`ownership` 扫账本仍未命中时，把 agentId 加进 `misses`；下次查询先看 `owners`，再看 `pending`，再看 `misses`，命中 `misses` 就直接返回 undefined，不再读账本。
