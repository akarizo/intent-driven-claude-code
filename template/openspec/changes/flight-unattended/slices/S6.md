  - 改文件一律用 Edit / Write，路径写字面绝对路径；不要用 `sed -i`、`python3 -c` 改文件，不要用 heredoc，不要把输出重定向到 worktree 以外；

## `press-approves-then-resumes` 的新断言（flight.test.tsx）
- **Given**：批准带上已停飞的 alpha（计划改过，指纹 G，baseline 以 exit 0、`{ok: true, reasons: []}` 作答）与 beta（计划未改，指纹 F）。
- **When**：按下 alpha 的 `replan:alpha:<G>`；让 beta 成为最新一项后按下 `resume:beta:<F>`；推进时钟，让后台续飞跑完。
- **Then**：
  - 账本恰好追加一条 approve（alpha，fp G）；
  - baseline 只为 alpha 跑过；
  - 预填记录（`log.fills`）依次为 `/opsx-apply alpha 授权提交`、`/opsx-apply beta 授权提交`；
  - 通知里有一条含「回车续飞」。
- attempt 2 的版本断言 `fills` 为空、通知含 `worktree-beta`（真实起飞的回复）。这两条都要换掉。
