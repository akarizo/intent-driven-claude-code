# S3 · 编排加固：飞行中指纹失败如实停飞；派发执行体前提交记录；有 agent 在跑时不重复起飞；读缺失文件不停飞；版本 0.2.1

## 做什么
`template/plugins/flight/hooks/orchestrator.tsx`（`ctxOf` 的 `log` 已由 S2 接到 `$.ui.log`）：

1. **`driveNow` 的指纹**：现在是 `const fpNow = (await judge(...plan_fp...)).stdout.trim()`。改为检查退出码和 `/^[0-9a-f]{64}$/`：
   - 不合格就 `await runLandingAction(ctx, f, { kind: 'halt', reason: \`计算计划指纹失败：${firstLine(r.stderr) || firstLine(r.stdout) || '无输出'}\` })` 并 return；
   - 不再交给 `nextActions` 去比对。
2. **`perform` 的 dispatch executor 分支**：`ensureWorktree` 之前先 `const err = await commitRecords(io, f, 'chore(flight): 记录')`（`./land` 已导出）。有 err 就 `return blocked(a.slice, \`提交飞行记录失败：${err}\`)`。
3. **`takeoff` 的「正在飞」检查**（约 306 行）：去掉「最新 attempt 未 land / halt」这个前提。只要最新 takeoff 那次飞行派出的任一 agent 在 `$.agent.list()` 里是 pending / running / waiting，就回复 `flight：${name} 上一次飞行派出的 agent 仍在运行（attempt ${state.attempt}），等它们结束再起飞`，不写账本。
4. **版本**：`template/plugins/flight/.claude-plugin/plugin.json` 的 version 改为 `0.2.1`。
5. **`ioHere.read`**（首飞实况：S1 合回后刷新接口摘要，`$.fs.read` 对还不存在的 `slices/_interfaces.md` 抛 `ENOENT`，飞行停飞）：先 `$.fs.exists(path)`，不存在返回 `undefined`；存在再 `$.fs.read`，其他错误照常抛出。
