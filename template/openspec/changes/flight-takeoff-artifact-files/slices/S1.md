# S1 · 插件：artifact_files 并入工件、批准带计数、工件之外拒绝给出路

先读 `design.md` 的 D1、D2、D4。

## 做什么
1. **`template/plugins/flight/hooks/land.ts`**：`classifyDirty(paths, x)` 的 `x` 增加可选 `artifactFiles?: readonly string[]`；artifacts 判定追加精确匹配 `x.artifactFiles?.includes(p)`（records 判定仍在最前）。更新函数上方注释。
2. **`template/plugins/flight/hooks/orchestrator.tsx`**：
   - 在 `scenarioFiles` 旁新增并导出 `artifactFiles(io: Io, path: string): Promise<string[]>`：读 `slices.json` 的 `artifact_files`，只留字符串项；读不出 / 非 JSON / 非数组 → `[]`。
   - `takeoff()` 调 `classifyDirty` 时传入 `artifactFiles`。
   - 工件之外的拒绝信息改成 D4 的文案：首行不变，后接路径，再接「授权提交」不覆盖说明与两条出路（`<change>` 换成实际 change 名）。出路段不得含「未提交的只有本 change 的工件」。
3. **`template/plugins/flight/hooks/register.tsx`**：`artifactCount` 调 `classifyDirty` 时同样传入 `artifactFiles(ioOf($), \`${c.changeDir}/slices.json\`)`。
