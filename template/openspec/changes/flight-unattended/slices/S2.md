## 做什么（design D4 的 G9、D8；接口见 `slices/_interfaces.md`）

### `template/.claude/hooks/slice-gate.py`
- **`final` 加 `--integ-base SHA`**：
  - 给了它就在原有判据之外加判 G9，对 `git diff SHA HEAD` 判，规则见 design D4 的表；
  - 失败项以 `G9 integ:` 开头并点名文件（scenario 测试点名函数名）；
  - G9 不依赖全量测试：G7 红时也照判。
- **scenario 测试判定**：
  - 从 `scenario_tests` 取映射到的 `<文件>::<函数>`，只处理 `.py`；
  - 用 `ast` 分别解析 SHA 版本（`git show SHA:<file>`）与工作树版本，取该函数的 `lineno..end_lineno`；
  - `git diff -U0 SHA HEAD -- <file>` 的 hunk 行号（旧侧对 SHA 版本、新侧对 HEAD 版本）与区间有交集即判红；
  - 某一侧文件不存在或解析失败：按「该侧无此函数」处理；两侧都没有就不判。
- **测试文件判定**：
  - 路径含 `tests/`，或文件名匹配 `test_*.py`、`*_test.py`、`*.test.ts`、`*.test.tsx`；
  - 在 `git diff -U0` 的 `-` / `+` 行里，计数 assert（`assert `、`expect(`）、测试函数（`def test_`、`test(`、`it(`），并找新增的 skip / xfail 标记（`pytest.mark.xfail`、`pytest.mark.skip`、`pytest.skip(`、`.skip(`、`.todo(`）。
- **工件判定**：
  - change 目录取 `--change-dir` 相对仓库根的路径；
  - 命中 `proposal.md`、`design.md`、`tasks.md`、`slices.json`、`slices/`、`specs/`，或仓库内任意 `openspec/adr/` 下的文件即判红。
- **`FEATURES`** 加 `"integ-guard"`；文件头注释的子命令说明同步。

### `template/.claude/hooks/ledger.py`

- 写一个可复用的「可选字段」校验，不要为 halt 单写分支。

### `template/.claude/hooks/timeline.py`
- **`report`**：
  - 有 heal 时打印「自愈：k 次」，并逐条打印 `<kind> <slice>`；
  - 有 triage 时打印「停飞诊断：<text 首行>」（多条取最后一条）。
- **`render`**：timeline.md 记 heal（`heal <kind> <slice>`）与 triage（`triage <首行>`）两类行，沿用现有行格式。
- 现有输出不变（其它测试依赖）。
