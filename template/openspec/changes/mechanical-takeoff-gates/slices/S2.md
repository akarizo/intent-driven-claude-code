## 现状

`workflow_agents(wf_dir)` 已返回 `(label, phase, model, turns, wall)` 列表并打印"各 agent 实际模型 + 模型分布"。缺的只是对账。

## 契约

```
python3 .claude/hooks/session-decompose.py --session S --workflow DIR --expect-models '{"executor":"opus","reviewer":"opus","integrator":"sonnet"}'
```

- 阶段 → 角色：`Implement` / `Fix` → `executor`；`Review` → `reviewer`；`Finalize` → `integrator`；其他阶段跳过对账（只打印）。
- 比较**别名**不比原始 id（D5）：实际 id 经 `alias_of` 归一后与期望别名比；`alias_of` 返回 `None`（第三方 id）一律记不符。
- 一致 → 追加一行 `路由对账：✅ 一致（executor=opus · reviewer=opus · integrator=sonnet）`，exit 0。
- 不符 → 逐条 `❌ <label> · <phase> · 期望 <alias> · 实际 <id>`，最后 exit 3。
- **不传 `--expect-models` → 行为与今日完全一致**（只打印，exit 0）。
- 加载 `alias_of`：`importlib.util.spec_from_file_location` 按同目录 `session-model.py` 路径加载（文件名含连字符不能 import，`tests/conftest.py` 有同款写法）。加载失败 → warn 一行并退化为只打印（不阻断收口）。
