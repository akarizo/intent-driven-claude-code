# S3 · 门禁红次数与测量统计取自账本；test-evidence 对账本模式切片让位

## 前置
S1 已合回：`ledger.py` 认识 measure 事件（字段：attempt、slice、agent、base、commit、outcomes、changed、source）。

## 做什么

### 1. `template/.claude/hooks/timeline.py` 的 `report`
- **读账本**：`import ledger`（脚本目录在 `sys.path` 上，`takeoff-gate.py` 就是这样做的），调用 `ledger.read_events(change_dir)`。
- **账本里有 takeoff 时**：
  - `门禁红次数：N（账本：切片门禁 x · final y）`：x 是 `ev == "gate"` 且 `ok is False` 的条数，y 是 `ev == "final"` 且 `ok is False` 的条数，N = x + y，不分 attempt。
  - 再打印一行 `测量：n 次（见红 m 次）`：n 是 measure 事件数，m 是其中 `outcomes` 里有 `FAILED` 或 `ERROR` 的条数。
- **没有账本或没有 takeoff**：照现状按 timeline 行统计。
- **读账本抛异常**：按 timeline 统计，并在那一行末尾附 `（账本读取失败，按 timeline 统计）`。
- 其余输出（事件表、批准 → apply 完成、批准 → PR 打开、切片用时）不变。

### 2. `template/.claude/hooks/test-evidence.py`
`find_change` 读到的切片标记里 `evidence == "ledger"` 时，`main` 直接返回，不写 evidence.log。标记没有这个字段时行为不变。
