## `slice-gate.py` CLI 契约

```
slice-gate.py lint     --change-dir DIR                 # 校验 slices.json；stdout 打印 waves JSON；违规 exit 2 并在 stderr 点名规则
slice-gate.py waves    --change-dir DIR                 # 只打印 waves JSON
slice-gate.py start    S --change-dir DIR               # 在 git toplevel 写 .openspec-slice = {"slice","change_dir","base":HEAD,"started"}；timeline 记 slice-start
slice-gate.py gate     S --change-dir DIR [--base REF]  # 跑 G1–G7；stdout 打印 JSON；追加 gate-report.md；timeline 记 gate；ok 时删 .openspec-slice
slice-gate.py final    --change-dir DIR                 # 全量 test/lint/typecheck + 全部 scenario 状态；JSON 含 scenarios{total,passed}
slice-gate.py baseline --change-dir DIR                 # 跑 gate.test 一次，把耗时写回 slices.json.gate.full_suite_sec
```

JSON 契约：`{"slice": "S1", "ok": true, "commit": "<sha>", "failed": [], "warnings": [], "summary": "..."}`。`failed` 每项以 `G<n>` 开头并点名对象。

## lint 规则

- 切片数 1–9（`count`）；deps 引用存在且无环，深度 ≤ 3（`depth`）；每片 `owns` 1–12 条（`owns`）；`verify` 非空（`verify`）；同一 wave 内任意两片 owns 不相交（`overlap`，glob 相交按前缀 / fnmatch 双向判定）。
- waves：Kahn 分层——第 i 层 = 所有 deps 都在前 i-1 层的切片。

## gate 检查项

| # | 检查 | 判据 |
|---|---|---|
| G1 | verify | `slices[S].verify` exit 0 |
| G2 | lint / typecheck | `gate.lint` / `gate.typecheck` 若非空则 exit 0（全量 test 只在 final 跑） |
| G3 | 源码-测试配对 | 区间内改动的非测试源文件（排除 .md/.txt/.rst/.html、json/yaml/toml/ini/lock、`.claude/**`、`openspec/**`、`docs/**`）≥1 时，区间内必须也改动了 ≥1 测试文件（路径含 tests/test/__tests__/spec 目录，或 `test_*.py` / `*_test.py` / `*.test.*` / `*.spec.*`） |
| G4 | GWT | 区间内改动的测试文件里每个测试函数（Python `def test_`；JS/TS `test(` / `it(`）函数体内按序含 `Given:` `When:` `Then:` |
| G5 | RED 先于 GREEN | `<change>/evidence.log` 中本切片存在一条 FAIL 早于最后一条 PASS；不满足只进 `warnings` |
| G6 | 所有权 | 区间内改动文件 ⊆ owns（fnmatch，`**` 允许跨目录）∪ change 目录 ∪ `.openspec-slice`；违规 fail 并点名路径 |
| G7 | scenario 状态 | `scenario_tests[id]` 指向的函数存在且其装饰器不含 `xfail` / `skip`；缺失或仍标记 → fail |

区间 = `<base>..HEAD`（base 来自 `.openspec-slice` 或 `--base`）；工作树若有未提交改动，加入 `warnings`。gate.test 缺省自动探测：package.json→`npm test`，pyproject/pytest.ini→`python3 -m pytest -q`，go.mod→`go test ./...`，Cargo.toml→`cargo test`。

## `intent-gate.py` 改动

1. 定根：从目标文件所在目录向上找最近含 `openspec/` 的目录作为 root，找不到再回退到 `CLAUDE_PROJECT_DIR`；root 之外的文件不管。
2. 所有权：root 下存在 `.openspec-slice` 时，读其 `change_dir/slices.json`，目标文件（非豁免）不匹配该切片 owns → deny，理由含切片 id 与路径。豁免名单不变。
3. fail-open 不变。
