# S2 · 工作流：integrator / final-gate 抛错重派一次，评审员抛错只记录；回退路径同步

**目标**（design D2）：工作流不因任何单个 agent 抛错而整体崩溃。机械角色重派一次，评审员缺失留下 blocked 记录。

## 契约

```text
integrator：
  const callInteg = (retry) => agent(..., { label: `integrate:w${i + 1}` + (retry ? ':retry' : ''), ... }).catch(() => null)
  let integ = await callInteg(false); if (!integ) integ = await callInteg(true)
  !integ        → blocked { slice: `wave${i+1}`, kind: 'infra', reason: 'integrator 未返回（已重派一次）' }
  integ.ok 为假 → 维持现状（冲突是确定性的，不重派）
评审员：
  reviews.push(agent(...).catch(() => { blocked.push({ slice: `review:${s}`, kind: 'infra', reason: '切片 ' + s + ' 评审未返回（不重派，PR 评审兜底）' }); return null }))
final-gate：
  同 integrator，label 'final-gate' / 'final-gate:retry'；仍为空 → blocked { slice: 'final', kind: 'infra', reason: 'final-gate 未返回（已重派一次）' }，返回的 final 为 null
回退路径（命令与 skill 同改，原样含下列措辞）：
  「integrator 与 final 抛错或未返回时重派一次，仍失败记 blocked（infra）」
  「评审未返回只记录（blocked，infra），不重派——切片级评审缺失由 /pr-ship 的整 PR 评审兜住」
```

## 坑

- ⚠ **重派的 label 要能被测试区分**：`integrate:w1:retry`、`final-gate:retry`。`TAIL_REPLIES` 里的 `^integrate:` 会匹配到重派 label，骨架已按「先写的规则先匹配」排好。
- ⚠ **每个 `agent(` 调用都必须显式带 `model:` 与 `effort:`**：`test_workflow_routes_models_explicitly` 按 `agent(` 出现次数对账。
- ⚠ 脚本禁止 `Date.now` / `Math.random` / `import(`。每处 `blocked.push` 都要带 kind（`test_workflow_blocked_entries_carry_kind`）。
- ⚠ 不要改执行体与 fix 的既有兜底，它们已有用例覆盖。
- ⚠ 逐条去掉 4 条骨架的 `@pytest.mark.xfail`。
