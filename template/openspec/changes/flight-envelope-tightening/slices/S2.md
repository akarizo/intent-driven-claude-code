# S2 · 合回检查补规格；清理 land 测试里失效的 `--is-ancestor` 预设

## 背景
本片的 4 个 scenario（`flight-merge-guards#merge-*`）描述的是 #41 修复体与 R2、R3 已经实现、并有测试覆盖的行为。本 change 只给它们补规格并映射到这些测试（铁律 1、2），所以测试本来就是绿的。

本片的实际工作是清理测试替身。

## 做什么
`template/plugins/flight/tests/land.test.ts`：
1. 生产代码已经不调用 `git merge-base --is-ancestor`（R3 改用合并提交的第二父判定），但测试替身还留着它的预设。要删掉的有：
   - `fakeIo` 默认预设里的 `--is-ancestor` 分支；
   - `land-records-already-integrated-slice` 与 `land-refuses-zero-commit-slice-as-integrated` 两个用例里的 `--is-ancestor` 桩。
2. 同步改这两个用例的 `// Given:` 注释：只描述尖端在第一父链上、或是合并提交的第二父，不再提「是 HEAD 的祖先」。
3. 改完后上面两个用例和 `land-refuses-direct-commit-in-owns`、`land-refuses-merge-without-change` 必须仍然通过。

`tests/test_flight_land.py`：只核对 4 个包装的 Given/When/Then 注释与 spec 一致，不改断言。
