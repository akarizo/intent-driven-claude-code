# S4 · `spec_html.py` 脚本渲染器与飞行计划区

**目标**：spec.html 由脚本确定性渲染，零 token；新增飞行计划区。

## 产物（owns）

- `template/.claude/hooks/spec_html.py`（新）
  - CLI：`spec_html.py --change-dir DIR [--template PATH] [--out PATH]`；template 缺省为 `<hooks 同级>/../skills/spec-html-render/templates/spec.html.tmpl`，out 缺省 `<DIR>/spec.html`。
  - 沿用模板的 block 契约（`<!-- block:NAME -->…<!-- /block:NAME -->` 整段替换、保留 marker）。块与规则按 `template/.claude/skills/spec-html-render/SKILL.md` 的表：title / change-name / meta-chips（从 `openspec status --change <name> --json` 读，读不到则按文件存在判 done）/ why / what / capabilities / specs（Requirement → `.requirement`，Scenario → `.scenario` + `<ul class="steps">` + `<span class="step-key" data-kw>`）/ design（二级标题一块，Decisions/Risks 用 details）/ diagrams（```mermaid 块 → `.diagram-frame` + `.mermaid` + `<pre class="diagram-fallback">`）/ adrs（扫 `<openspec>/adr/`，解析 Status / Supersedes，DRAFT 单独一组）/ tasks（`- [ ]`/`- [x]` → checkbox）/ footer。mockups 块不生成，保留占位。
  - **新增 `block:flight`**：读 `slices.json` + `timeline.md` + `gate-report.md`（可缺）：切片表（id / 标题 / wave / deps / owns / verify）、scenario↔test 映射表（状态：骨架含 xfail → `pending`，无 xfail → `unlocked`，gate-report 有 ok 记录 → `passed`）、时间事件表。模板需加 `<section id="flight">` 与 TOC 项（位于 tasks 之前）。
  - 极简 markdown → HTML：标题、段落、无序/有序列表、行内代码、粗体、代码块；HTML 转义所有正文。
  - 幂等：同输入两次输出除 footer 时间外一致（footer 时间由 `--now` 参数或环境 `SPEC_HTML_NOW` 注入，缺省取当前时间）。
- `template/.claude/skills/spec-html-render/SKILL.md`（改）：8 步流程替换为「运行 `python3 .claude/hooks/spec_html.py --change-dir openspec/changes/<name>`」+ 失败只 warn + 触发时机不变；保留设计原则与 Guardrails 中仍成立的条目（Mermaid 脚本段、一次 Write、幂等）。
- `template/.claude/skills/spec-html-render/templates/spec.html.tmpl`（改）：加 flight 节与 TOC 项；其余不动。
- `template/.claude/commands/spec-html.md`（改）：步骤 2 改为调用脚本。
- `tests/test_spec_html.py`（新）：用 tmp change 目录（含 slices.json、timeline.md）渲染，断言块内容与飞行区。
