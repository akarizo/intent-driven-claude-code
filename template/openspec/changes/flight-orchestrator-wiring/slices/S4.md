# S4 · landing.tsx 改为只收 Ctx 的落地逻辑

## 做什么
1. **`core.ts` 新增两个类型**（只加类型，其他不动）：
```ts
/** 「这个 agent 属于哪次飞行」的查找结果（io.flightOfAgent 的返回） */
export type Found = { flight: Flight; events: FlightEvent[] }
/** hook 文件从 $ 造的上下文：全是闭包，可以跨文件传（实测 X12：$ 本身不能跨 import） */
export interface Ctx {
  io: Io
  now(): Promise<number>                      // 毫秒时间戳，用于事件的 at
  spawn(x: { f: Flight; role: Role; cwd: string; prompt: string; description: string }): Promise<{ agentId?: string; deny?: string }>
  status(text: string | undefined): Promise<void>
  toast(text: string): Promise<void>
  runCommand(command: string, args: string): Promise<void>
}
```
2. **重写 `landing.tsx`**：不注册 hook，不 import `claude-code` 的运行时值，不碰 `$`。导出：
```ts
export const FINDINGS_TOOL: { name: 'submit_findings'; description: string; inputSchema: Record<string, unknown> }
/** submit_findings 的处理：只认当前 attempt 里 role 为 reviewer 的调用者；校验通过就追加 review 事件 */
export async function onFindings(ctx: Ctx, found: Found | undefined, agentId: string | undefined, input: unknown): Promise<{ result: string } | { deny: string }>
/** 评审员 / 修复 agent 收口；其他 role 返回 undefined（交给调用方放行） */
export async function onLandingStop(ctx: Ctx, found: Found, agentId: string): Promise<{ block: string } | undefined>
/** drive 交来的 dispatch reviewer / fixer、final、land、halt；其他动作直接返回 */
export async function runLandingAction(ctx: Ctx, f: Flight, action: Action): Promise<void>
```
   **复用**：逻辑大体照搬 3a S8 那次未合入的提交，用 `git show bcb74e6:template/plugins/flight/hooks/landing.tsx` 与 `git show bcb74e6:template/plugins/flight/tests/landing.test.tsx` 读。把其中的 `$` 调用换成 `ctx` 的闭包：
   - `ioHere($)` → `ctx.io`
   - `spawnHere(...)` → `ctx.spawn(...)`
   - `$.clock.now()` → `ctx.now()`
   - `$.ui.status` → `ctx.status`
   - `$.ui.toast` → `ctx.toast`
   - `$.command.run({command: 'pr-ship', args})` → `ctx.runCommand('pr-ship', f.change)`
   
   `flightOfAgent` 的查找由调用方做，以 `found` 传入。
   **新增**：final 动作在跑 `slice-gate.py final` 之前，先调用 `land.commitRecords(ctx.io, f, 'chore(flight): 记录')`（S1 导出），否则收口时 ship 会判「final 过期」。
3. **`register.tsx` 删掉 `registerLanding` 的 import 与调用**（landing 不再注册 hook），其余一行不动。

## scenario → 同名 TS 测试（landing.test.tsx）
findings-tool-accepts-flight-reviewer · findings-tool-denies-others · reviewer-stop-without-findings-blocks-once · fixer-stop-runs-final · landing-runs-pr-ship · final-red-halts

**测试写法**：直接 import landing 的三个函数，用假 `Ctx` 调用，不走 hook。实测 X13：测试与插件是隔离实例，走 hook 时测试登记的状态插件看不到。
- 假 `Ctx.io.run` 按 argv 分派并记录调用：
  - **账本**：`git hash-object -w --stdin` 的 stdin 就是事件 JSON，存进数组；`ledger.py show` 逐行返回。
  - **门禁**：`slice-gate.py final` 返回预设 JSON。
- `Found` 由测试按账本数组直接构造。
- `landing-runs-pr-ship` 另断言：`commitRecords` 的 `git commit` 发生在 `slice-gate.py final` 之前。
