## 做什么（`install.sh`，design D5）

### 1. `merge_settings`（约 :297 起）
在合并 fragment 之前，先从目标 `.claude/settings.json` 的各事件里，移除 hook 命令串与退役清单**完全相同**的项。

退役清单（历代模板 `hooks.json` 下发的原样写法）：
- `python3 "$CLAUDE_PROJECT_DIR/.claude/hooks/takeoff-gate.py"`
- `python3 "$CLAUDE_PROJECT_DIR/.claude/hooks/slice-gate.py" checkpoint`
- `python3 "$CLAUDE_PROJECT_DIR/.claude/hooks/stop-gate.py"`

动手前用 `git log -p -- template/.claude/hooks/hooks.json` 核对有没有别的写法，有就一并列入。

规则：
- **匹配粒度**：一个 entry 的 `hooks` 里任一命令命中就去掉该命令；`hooks` 空了就去掉整个 entry；事件数组空了就去掉事件键。
- **用户自写的命令一律不动**：哪怕调用同一个脚本、只是写法不同，例如带额外参数。
- **有移除时**：标记为已改动，并让外层打印「已移除 N 条退役 hook 注册」。

### 2. 收尾摘要
- **列出退役文件**：目标里存在以下文件时，列出这些文件，并提示「已退役，可手动删除」，**不删除**：
  - `.claude/workflows/opsx-apply.js`
  - `.claude/agents/integrator.md`
  - `.claude/agents/slice-executor.md`
  - `.claude/hooks/session-decompose.py`
- **改写旧引擎的说法**（约 :424-425、:531、:534、:541-542）：
  - 不再提 opsx-apply.js、slice-executor、integrator、Workflow 并行；
  - takeoff-gate 的那行改为「插件起飞时用 takeoff-gate 比对账本批准指纹」。
- **必须保留的字样**：`takeoff-gate` 与 `session-model.py`。`tests/test_docs_iron_rules.py` 断言它们出现在 install.sh 里。
