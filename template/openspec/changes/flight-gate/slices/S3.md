# S3 · hooks.json 注册 + explore / apply / propose 命令与 skill 同改

**目标**：把 S2 的脚本挂上去；把 S1 的握手语义与 explore 的边界写进人读得到的命令文本——命令与 hook 判据同改，禁漂移。

## owns

- `template/.claude/hooks/hooks.json`
- `template/.claude/commands/opsx-explore.md`
- `template/.claude/commands/opsx-apply.md`
- `template/.claude/commands/opsx-propose.md`
- `template/.claude/skills/openspec-explore/SKILL.md`
- `template/.claude/skills/openspec-apply-change/SKILL.md`
- `template/.claude/skills/openspec-propose/SKILL.md`
- `tests/test_template_docs.py`（骨架已在，去掉 xfail 标记即解锁；文件里其它测试不要动）

## 依赖的接口

- **S1**：`takeoff-gate.py` 判据变为两段式——起飞指令只算发起，批准是发起之后一条 ≤ 40 字、含批准词、不含 change 名与路径的人类消息；CLI `--change-dir` 非 0 时 stderr 已含主模型 · 规模 · worktree 与 spec.html 绝对路径 · 补救指引。
- **S2**：`phase-gate.py` 只从 stdin 收 hook JSON，只处理 `PreToolUse`，无 CLI 参数。

## 要做的改动

### 1. `hooks.json`（hook 唯一真源，`install.sh` 幂等合并进目标 `settings.json`，**不要改 `settings.json`**）

`PreToolUse` 追加一条 `"matcher": "Write|Edit|Bash"` → `python3 "$CLAUDE_PROJECT_DIR/.claude/hooks/phase-gate.py"`。既有三条（`intent-gate` 的 `Write|Edit`、`takeoff-gate` 的 `Workflow|Agent|Task`、`intent-reminder` 的 `UserPromptSubmit`）原样保留，顺序不变。

⚠ 改完必须仍是合法 JSON：`python3 -c "import json;json.load(open('template/.claude/hooks/hooks.json'))"`。

### 2. `opsx-explore.md` + `openspec-explore/SKILL.md`

Guardrails 增三条硬边界（两份措辞一致）：不产出 `slices.json` · `tasks.md` · `slices/*.md`；不跑 baseline；不派实现类子 agent（`slice-executor` · `integrator`）。工件成形后**引导人显式 `/opsx-propose`**，不在同一轮继续。

保留既有定位：`proposal.md` · `design.md` · `specs/**` 仍可在 explore 内写。**删掉** "Ending Discovery → Flow into a proposal" 里把 explore 直接推进到飞行的措辞。

### 3. `opsx-apply.md` + `openspec-apply-change/SKILL.md`

- **step 0** 写明起飞是**两段式握手**：起飞指令只是发起；step 0 跑 `takeoff-gate.py --change-dir …`，非 0 时把 stderr 那段（主模型 · 规模 · worktree · `spec.html` · 补救指引）原样交给人并**停下**，等人一句短确认，不进入后续任何步骤；该判定由 hook 强制，命令自身不重复判断。
- **派发参数一律机械推导**，不要求人提供，明确写出来源：`waves` ← `slice-gate.py lint` · `deps` ← `slices.json` · `expectHead` ← `git rev-parse --short=10 HEAD` · `changeDir`/`hooksDir`/`agentsDir` ← 仓库布局 · `<main>` ← `session-model.py`。
- 既有的 `session-model.py` 取 `<main>`、`--expect-models` 收口对账、四种暂停例外**原样保留**。

### 4. `opsx-propose.md` + `openspec-propose/SKILL.md`——收尾交付一行自足起飞指令

现状收尾只打印 `spec.html` 绝对路径 + 一句"请你自己发出 `/opsx-apply <name>`"。人切模型起飞要先 `/clear`，清空后既不知道进哪个目录，也无从复原参数。**硬交接三件事改四件**，新增打印**一行**可直接复制的起飞指令：

```
去 '<worktree 绝对路径>' apply <name>, 授权你git提交, 完成后就pr-ship, 把pr url交付我review
```

- worktree 路径用 `pwd` 拼成**绝对路径**，不得写相对路径。
- 授权语固化在这一行里（授权范围与 git 铁律"命令即授权"一致：commit · push feature 分支 · 建 PR · 贴评审 · draft↔ready）。
- **不得**把 `waves` · `deps` · `expectHead` · `hooksDir` · `agentsDir` 等派发参数列进那一行让人复制——它们由起飞会话自己推。
- 既有三件事（`spec.html` 绝对路径 · 本命令到此结束 · 工件单独 commit）原样保留。
