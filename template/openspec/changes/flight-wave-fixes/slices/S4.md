## 事实基线（main a88a97b）

- `template/openspec/.gitignore` 现有 2 行：注释 + `.mini-active`。
- `install.sh`：345–346 行 `copy_tree "$TEMPLATE_SRC/openspec" "$TARGET/openspec" 0`（openspec/ 从不覆盖）；394–409 行根 `.gitignore` 的 `.worktrees/` 幂等追加是可仿照的写法（`grep` 判存在 → `log_skip`；否则 `printf … >>` + `log_app`）。
- `install.sh` 只用 `command -v openspec` 检查 CLI 是否存在（100–110 行），并不调用它；测试用 PATH 桩代替。
- `tests/test_docs_iron_rules.py` 读 `install.sh` 文本（断言含 `takeoff-gate` 与 `session-model.py`），不要删这些字样。

## 契约

```
template/openspec/.gitignore 追加：
  # 飞行起飞记录（apply 起飞到收口之间的每机瞬态，收口即删，不入库）
  changes/*/.flight

install.sh（copy_tree openspec 之后；install 与 --upgrade 都跑）：
  OPENSPEC_GITIGNORE="$TARGET/openspec/.gitignore"
  整行 changes/*/.flight 已在（grep -qxF）→ log_skip + SKIP_COUNT+1
  否则 → printf '\n# 飞行起飞记录（…）\nchanges/*/.flight\n' >> 该文件 + log_app
```

## 坑

- ⚠ 用整行匹配（`grep -qxF`），避免注释里的同名字样被误判为已存在。
- ⚠ `set -euo pipefail` 下 `grep` 未命中返回 1，要放在 `if` 条件里。
- ⚠ 不动根 `.gitignore` 那一段；不改 `copy_tree` 的覆盖语义。
