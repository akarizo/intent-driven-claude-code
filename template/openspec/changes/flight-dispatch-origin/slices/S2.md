# S2 · 派发凭证强制：guardedSpawn、ctxOf 带凭证、hook 入口取凭证

依赖 S1 与 S3。S1 已把定时到点改为唤醒；S3 已建好 `lease.ts`，并让批准带把凭证传给 `takeoffNow`。本片打开强制：没有活凭证的派发当场拒绝。接口见 `slices/_interfaces.md`。

## 做什么（design D4）

### `template/plugins/flight/hooks/lease.ts`
1. 加 `guardedSpawn(lease, spawn)`：`leaseDeny(lease)` 有值时返回 `{ deny }`，且不调用 `spawn`；否则 `return spawn()`。

### `template/plugins/flight/hooks/orchestrator.tsx`
2. **`ctxOf($, lease?: Lease)`**：
   - `spawn` 内先 `const r = await guardedSpawn(lease, () => $.agent.spawn({...}))`；`r` 带 `deny` 就原样返回；
   - 其余（`markPending` 等）不变。
   - 不带 `lease` 的 `ctxOf($)` 调用照常可用：读写账本、通知、状态行等不派发的用途都不需要凭证。
3. **凭证沿起飞与驱动传下去**：
   - `takeoff($, args, opts)` 的 opts 已有 `lease`（S3 加的类型），改为 `await drive($, flight, opts.lease)`；
   - `drive($, f, lease?)` → `driveNow($, f, lease)` → `const ctx = ctxOf($, lease)`；
   - `takeoffArmed` → `takeoffArmedLocked` → `runStep($, change, step, lease)` → `takeoffSafe($, args, { resume, lease })`；
   - `advanceArm($, change, event, lease?)`、`advanceAll($, event, pick, lease?)`、`agentEndedArms($, agentId, lease?)` 透传。
4. **hook 入口取凭证**，用 `withLease` 包住各 hook 的处理：
   - `command.run` `opsx-apply`：`withLease(lease => takeoffArmed($, args, { lease }))`；
   - `command.run` `flight`：`flightCommand` 加 `lease` 参数，resume 分支 `takeoffArmed($, rest, { resume: true, lease })`；
   - 子 agent 的 `turn.complete`：`drive($, f, lease)`、`advanceArm($, f.change, { kind: 'agent-ended' }, lease)`、`agentEndedArms($, e.agentId, lease)`；
   - 主会话的 `turn.complete`：`advanceAll($, { kind: 'main-turn' }, pick, lease)`；`pendingTriage` 的 `triage(ctxOf($, lease), …)`。
   - 定时器回调（`watchTick`、`watchOne`、`runStep` 的计时、`submitWake`、`baselineTick`）**不取凭证**。它们在 S1 之后本来就不派发。
5. **`landing.tsx`** 若需要改，只限于类型：它用调用方给的 ctx，不自己取凭证。

## 现有用例
- 不删不改断言。用例失败时先查管道：哪个 hook 入口没包 `withLease`，或者哪一层没透传 `lease`。
- 改完跑一遍 `claude plugin test template/plugins/flight`：除了本片新写、尚未实现的用例，其余都要绿。
