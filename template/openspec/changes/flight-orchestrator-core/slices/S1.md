# S1 · 账本接受并逐类校验飞行事件，approve 判定不变

## 做什么
`template/.claude/hooks/ledger.py` 现在只认 approve（`EVENTS = {"approve"}`，`_check_event` 对所有事件要求 `fp`）。改为按 `ev` 分派的逐类校验，表见 spec `flight-ledger-events`（下面原样摘录）。`latest_approval` / `approved` / takeoff-gate 的判据不变：只看最新 approve 的 `fp`。

| ev | 必需字段（除公共字段 v=1 / ev / change / at / by.plugin 外） |
|---|---|
| approve | `fp`：64 位十六进制 |
| takeoff | `attempt`：正整数；`fp`：64 位十六进制；`branch`：非空字符串；`waves`：字符串数组的数组；`model`：非空字符串 |
| dispatch | `attempt`；`slice`：非空字符串；`role`：executor / reviewer / fixer / resolver；`agent`：非空字符串；`model`：非空字符串；`worktree`：非空字符串 |
| gate | `attempt`；`slice`；`ok`：布尔；`commit`：字符串；`failed`：字符串数组 |
| ended | `attempt`；`agent`；`reason`：字符串；`model`：字符串或 null |
| merge | `attempt`；`slice`；`ok`：布尔；`commit`：字符串；`failed`：字符串数组 |
| review | `attempt`；`slice`；`agent`；`findings`：数组，每项 `severity` ∈ CRITICAL/HIGH/MEDIUM/LOW，`file` 字符串，`line` 整数，`summary`、`fix` 字符串 |
| blocked | `attempt`；`slice`；`kind`：gate / infra；`reason`：字符串 |
| final | `attempt`；`ok`：布尔；`commit`：字符串；`failed`：字符串数组 |
| land | `attempt`；`verdict`：ready / draft |
| halt | `attempt`；`reason`：字符串 |

- 允许表外的额外字段（gate 事件会带 `warnings` / `ceilings` / `base` 等）。
- 注意 Python 里 `True` 是 `int`：`attempt` / `line` 的整数校验要排除 bool；`ok` 的布尔校验用 `isinstance(x, bool)`。
- 不合法 → `LedgerInvalid(sha, "<ev> 的 <字段> …")`，沿用现有的「账本损坏：<sha8> <原因>」输出与 exit 4。
