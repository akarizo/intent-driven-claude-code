3. 再实现。

## 做什么

### 新文件 `template/plugins/flight/hooks/ship.ts`（design D5）
导出项与 `slices/_interfaces.md` 一致：`SHIP_TOOL`、`ShipJson`、`shipComment`、`shipPr`。
- **模块边界**：只经 `Ctx` / `Io` 访问外界，不 import claude-code 的运行时值，不调用 `$`；
- **可用的导入**：`core.ts` 的类型与 `currentAttempt`，`io.ts` 的 `appendEvent`、`judge`。

**`SHIP_TOOL`**：
- `name: 'ship'`；
- description 说明：落地并以 draft 建好 PR 之后调用，交出 change 名与 PR 号，由插件按账本裁决、贴评论、切换 draft / ready；只有主会话可用；
- `inputSchema` 照约定。

**`shipPr(ctx, f, state, pr)`**：按 design D5 的 9 步执行，任一步失败就返回 `{ deny: 'flight：<原因>' }`，并且不再执行后续步骤。
- **git 命令**：一律 `git -C <changeTree> …`。
- **gh 与判定器**：gh 命令与 `slice-gate.py ship` 的 cwd 都是 change worktree；`pr` 统一规整为数字串 n。
- **拒绝原因须含的文字**：
  - 未落地：「还没落地」；
  - origin 不含 `github.com`：「只支持 GitHub」，并说明 PR 保持 draft、由人决定；
  - pr 不合法：「PR 号」；
  - 头分支不符：期望的分支名与实际值；
  - 头 commit 不符：「先推送」与两边的 SHA 前 10 位；
  - ship 输出不是 JSON：「ship 输出无法解析」；
  - gh 失败：「贴评论失败」或「切换 PR 状态失败」，附 gh 的首行。
- **切换 PR 状态**：
  - 裁决为 ready、PR 是 draft：运行 `gh pr ready <n>`；
  - 裁决为 draft、PR 不是 draft：运行 `gh pr ready <n> --undo`；
  - 其余情况不运行。
- **ship 事件**：
  ```ts
  { v: 1, ev: 'ship', change: f.change, at: <ctx.now() 的 ISO>, by: { plugin: 'flight', session: f.session },
    attempt: currentAttempt(state), pr: <gh 返回的 url>, verdict, commit: <HEAD> }
  ```
  经 `appendEvent` 写入。写入失败时返回 deny，原因为「账本写入失败」。
- **result**：一行，含裁决、PR 状态的变化（转 ready / 退回 draft / 保持不变）与「已贴评论」；draft 时附上 reasons。

**`shipComment(j, { date })`**：格式见 design D5；严格按 spec `ship-comment-lists-findings` 的顺序与文字。

### `template/plugins/flight/hooks/io.ts`
- `EVENTS` 增加 `ship: { attempt: ATTEMPT, pr: NONEMPTY, verdict: oneOf('ready', 'draft'), commit: STR }`。
- `EVENT_TYPES` 随之包含 ship，不另改。

## 测试世界的写法
- **假 Ctx**：`io.run` 按 argv 应答。
  - git 的 `rev-parse HEAD`、`remote get-url origin`；
  - gh 的 `pr view`、`pr comment`、`pr ready`；
  - `python3 …/slice-gate.py ship`：应答一段 ShipJson；
  - 账本追加用到的 `hash-object` / `mktree` / `rev-parse -q --verify` / `commit-tree` / `update-ref`：可参照 `landing.test.tsx` 的世界。
  - 记下全部 argv，供断言调用顺序与「没有运行 gh pr comment / ready」。
- **`now()`**：固定为 2026-10-13 的某个时刻。
