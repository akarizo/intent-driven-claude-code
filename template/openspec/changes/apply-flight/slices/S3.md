# S3 · agent 定义与 `opsx-apply` 工作流脚本

**目标**：纪律写进 agent 定义，编排写进确定性脚本。

## 产物（owns）

- `template/.claude/agents/slice-executor.md`（新）
  - frontmatter：`name: slice-executor`、`description`、`tools: Read, Edit, Write, Bash, Grep, Glob`、`model: inherit`、`permissionMode: acceptEdits`、`maxTurns: 40`、`skills: [test-driven-development]`、`color: blue`
  - 正文纪律：① 第一步 `python3 .claude/hooks/slice-gate.py start <S> --change-dir <dir>`；② 只读切片包与 owns 内文件，只写 owns 内文件（写外面会被门禁拒绝，遇拒绝把路径写进 JSON 的 failed 而不是绕过）；③ 一轮多动作（并行 Read；测试与实现能一起写就一起写；verify 与 lint 一条 Bash）；④ 不加 `cd &&` 前缀、不为一行脚本先 `cat >`；⑤ TDD：先写或解锁 scenario 骨架（去 xfail），跑 verify 看它红，再实现到绿；⑥ 每切片一个 commit（`git add` 只加 owns 内文件）；⑦ 收尾运行 `slice-gate.py gate <S> --change-dir <dir>` 并把其 JSON **原样**作为最终输出，不写报告；⑧ 改了骨架断言必须在 summary 申报。
- `template/.claude/agents/integrator.md`（新）
  - frontmatter：`tools: Bash, Read, Grep, Glob`、`model: sonnet`、`effort: low`
  - 职责：把给定的 commit SHA 列表 `git merge --no-ff <sha>` 合回当前分支（冲突则 `git merge --abort` 并返回 `ok:false` 点名文件）；用 `cx symbols --file <owns>`（无 cx 则 grep `^def |^class |^export `）把已合回切片的公开接口写进 `<change>/slices/_interfaces.md`；按要求运行 `slice-gate.py final`；`timeline.py record`；返回 JSON。
- `template/.claude/agents/code-reviewer.md`（改）：删除 `integration` 模式与「Review 水位线」相关段；保留 `full` / `follow-up`；铁律新增「不重跑测试套件、不轮询、不 sleep；以 prompt 给的门禁报告与 evidence.log 为准；至多 1 次定向抽查命令」；输出格式段新增「prompt 要求结构化时输出 `{findings:[{severity,file,line,summary,fix}]}`」；阻断阈值不变。
- `template/.claude/workflows/opsx-apply.js`（新）：见审批页 §2 ④ 的骨架，补齐：`args = {change, changeDir, hooksDir, waves, useAgentTypes}`；`agentType` 仅在 `useAgentTypes !== false` 时传；每个 agent prompt 以「cwd 即仓库根」开头并给出完整 gate 命令；integrator 在多切片 wave 后合回并抽接口；评审 push 不 await；Fix 阶段 `Promise.all`；final 由 integrator 跑；返回 `{slices, blocking, final}`。脚本内禁用 `Date.now()` / `Math.random()`。
- `tests/test_agents_workflow.py`（新）：静态检查 frontmatter 字段、正文关键短语、`node --check`（无 node 时 skip 该断言）、`Promise.all(reviews)` 出现在 `phase('Fix')` 之后。

## 依赖接口（来自 S1 / S2）

- gate CLI 与 JSON 契约见 `slices/S1.md`；timeline `record` 见 `slices/S2.md`。
