# S1 · final 先判 G7；全量测试按基线逐条差分

先读 `design.md` 的 D1、D2 与 `slices/_interfaces.md`。

## 做什么
全部在 `template/.claude/hooks/slice-gate.py`：

1. **`cmd_final` 改顺序（D1）**：
   - 先 `scenario_status(root, data)`（G7），再 lint / typecheck（`gate_cmd_verdict`，不变），最后 G2；
   - G7 有违规 → 不跑 `gate.test`，warnings 追加「G2 全量未跑：G7 已红，scenario 全绿后重跑 final」；
   - JSON 形状、`append_report`、`timeline_record` 不变。
2. **新增 `run_test_gate(cmd, root)`（D2）**：
   - 在临时目录里放 junit 路径，环境变量 `PYTEST_ADDOPTS` = 原值 + ` --junitxml=<路径>`，其余环境照抄；
   - 解析 junit：每个含 `failure` 或 `error` 子节点的 `testcase` 记为 `classname::name`，去重、排序；
   - 可度量条件：rc == 1、junit 存在且可解析、输出里 pytest 汇总行恰好一行、汇总行的 failed + error(s) 合计 == 各 testsuite 的 failures + errors 合计；
   - 返回形状见 `_interfaces.md`；`why` 写不可度量的理由，例如「没有 junit 输出（不是 pytest？）」「汇总行 2 行（调用了多次 pytest？）」「计数不一致」「exit 2」。
3. **`cmd_baseline`（D2）**：用 `run_test_gate` 跑 `gate.test`：
   - rc 0 → 与现在一致；
   - 可度量且 rc 1 → 不进 reasons，`bl["test"]["failed"]` 记标识；`bl["warnings"]` 追加「预存红 N 条已记录，final 按基线差分」；
   - 其余 → reason「全量测试在基线上红（exit <rc>；按退出码判：<why>）」。
   - 其余字段（`exit`、`sec`、`full_suite_sec`）照旧。
4. **`cmd_final` 的 G2（D2）**：
   - rc 0 → 绿；
   - 可度量且 rc 1 → 新增 = 本次 − 基线 `test.failed`（缺失视为空集）：
     - 新增为空 → warnings「G2 test: exit 1，失败均为基线预存红（N 条已按基线排除）」；
     - 否则 failed「G2 test: exit 1（新增 k 条失败）」，后接至多 6 条标识（换行分隔）；
   - 其余 → failed「G2 test: exit <rc>（按退出码判：<why>）」并附 `_tail(out)`。
5. 文件头注释：`final` 一行写明「先 G7；G7 红不跑全量」；「G2 差分」一段补上 `gate.test` 的逐条差分。
