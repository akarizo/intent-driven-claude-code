# S1 · ship 的 final 新鲜度放行任一 change 的记账文件与接口摘要

## 做什么
`template/.claude/hooks/slice-gate.py`：
- `BOOKKEEPING`（约 1175 行）加上 `"slices/_interfaces.md"`。
- `_final_fresh(root, change_dir, final_commit)`：现在只放行 `<本 change 目录>/<记账文件>`。改为放行 `<changes 根>/<任一子目录>/<记账文件>`，其中 changes 根是本 change 目录的父目录。
  - 实现：把每个改动路径相对 changes 根拆成 `<name>/<rest>`，`rest` 在 `BOOKKEEPING` 里即放行；不在 changes 根下的路径一律不放行。
  - 其余逻辑不变：final 提交须是 HEAD 的祖先，任一 git 调用失败就判不新鲜。
