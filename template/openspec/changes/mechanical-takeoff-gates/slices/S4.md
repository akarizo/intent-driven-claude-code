## 事实基线（实测）

人类消息在转录里的形状（2026-09-10 会话实测）：

- 斜杠命令：`{"type":"user","isMeta":false,"userType":"external","message":{"content":"<command-message>opsx-apply</command-message> <command-name>/opsx-apply</command-name> <command-args>syscomponent-from-system-part</command-args>"}}`
- 纯文本：同结构，`content` 是人打的原话（实测出现过 `授权`、`不相等，起飞`）
- **不是人**：`<local-command-stdout>…`、`<task-notification>…`、`[Request interrupted by user]`、`<bash-input>/<bash-stdout>`、`tool_result` 块、`isMeta: true`、compact 注入的 `This session is being continued…`——这些必须排除，否则批准会被伪造成"人说过"

## 契约

```
python3 .claude/hooks/takeoff-gate.py --change-dir DIR [--session PATH]
  stdout  批准证据一行：<ISO 时间> · <人类原话摘要 ≤40 字>
  exit 0  批准成立
  exit 3  无批准 / 批准早于计划最后改动；stderr 给 spec.html 绝对路径与补救方式
```

hook 模式（无 `--change-dir`，从 stdin 读 PreToolUse JSON）：

1. 取 `tool_name`：非 `Workflow` / `Agent` / `Task` → 静默放行。
2. 在 `tool_input` 的 JSON 文本里找 `openspec/changes/<name>`：找不到 → 静默放行（**fail-open**，不影响无关派发）。
2.5 定位转录（依次尝试，全失败 → 放行）：payload 的 `transcript_path` → payload 的 `session_id` + glob `~/.claude/projects/*/<sid>.jsonl` → 环境变量 `CLAUDE_CODE_SESSION_ID` + 同一 glob。**本仓库现有 hook 只用过 payload 的 `cwd`，`transcript_path` / `session_id` 是否随 PreToolUse 下发未经实测**——所以按这个顺序退让，任何一步拿到就用，全拿不到就放行，不猜。
3. 找到 → 按 CLI 同一判据判定；不成立 → 打 `{"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"deny","permissionDecisionReason":"…"}}`，reason 含 `spec.html` 绝对路径 + "需人类显式 `/opsx-apply`"。
4. 脚本任何异常 → 放行（坏门禁不能锁死派发，与 `intent-gate.py` 同规矩）。

判据（design D7 / D8）：

- **人类批准**：转录里存在人类消息（`type=="user"` · `isMeta` 非真 · `userType=="external"` · 文本非 `tool_result`），且满足其一：含 `<command-name>/opsx-apply</command-name>` 或 `/opsx-bulk-apply`（可带该 change 名）；或整条消息 ≤ 40 字且含批准词 `批准|起飞|授权|approve|go ahead|ok 起飞`。
- **新鲜度**：该消息时间 ≥ 计划工件最大 mtime（`proposal.md` · `design.md` · `tasks.md` · `slices.json` · `specs/**/spec.md`）。
- 多条候选取**最新**一条。

## propose 收尾（命令与 skill 同改）

把"提示用户把工件单独 commit；说明「打开 spec.html 看飞行计划，运行 `/opsx-apply` 即视为批准」"改成硬交接：

1. 打印 `spec.html` 的**绝对路径**。
2. 明确一行：**本命令到此结束。不得在同一轮继续 `/opsx-apply`；起飞需要你自己发出 `/opsx-apply <change>`（`takeoff-gate.py` 会校验这条批准）。**
3. 仍提示 artifacts-only commit。
