## 做什么

### 1. `template/plugins/flight/hooks/prompts.ts`
- `executorPrompt` 的入参增加可选 `previous?: { branch: string; attempt: number }`。
- 给出时，在 TDD 那几行之后加一行：「上一次（attempt <k>）的分支 `<branch>` 留作参考：可 `git show` / `git diff` 读取，不得 cherry-pick 或 merge；一切以当前切片包为准。」
- 不给时提示词与现在完全相同。

### 2. `template/.claude/commands/pr-ship.md` 第 4 步
- 把 `BASE=…; git merge-tree "$BASE" …; grep -c "^<<<<<<<"` 换成 `git merge-tree --write-tree --name-only HEAD origin/<target-branch>`，并写明：
  - **退出 0**：无冲突，进入下一步；
  - **退出 1**：有冲突，输出第一行是树 id，其后直到空行是冲突文件。报告这些文件，停下交用户；
  - **其他退出码**：报告错误并停下。
- 注明需要 git ≥ 2.38。「不算本命令的问询预算」等原有说明保留。

### 3. `template/.claude/commands/opsx-apply.md` 与 `template/.claude/skills/openspec-apply-change/SKILL.md`（同改，禁漂移）
- **Input 段加入 `--takeover`**：只在「最新一次起飞来自另一个会话、尚未落地或停飞，而且你已确认那个会话已结束」时使用；不加时插件会拒飞并提示。
- **在描述插件行为的段落里加一条**：
  - 续飞时新派发的执行体、修复体、解冲突 agent，遇到同名 worktree 已存在，会另起 `<名>-a<attempt>`，旧现场原样保留，清理由人执行；
  - 续接只在计划没变时复用原现场。
