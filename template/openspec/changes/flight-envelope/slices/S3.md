# S3 · 能力包络的纯策略模块 envelope.ts

## 做什么
新建 `template/plugins/flight/hooks/envelope.ts`，全部是纯函数：
- 不碰 `$`，不 import `claude-code` 的运行时值（实测 X12：`$` 不能跨 import）。
- 运行环境没有 Node：路径规范化、glob 匹配都要自己写，不能用 `path`、`minimatch`。
- 可以 import `./core` 的类型（`Role` 等）。

S6 会按下面的接口接线。**签名照此实现**，需要辅助函数可以另加导出：

```ts
import type { Role } from './core'

export type Who = { role: Role; worktree: string; owns: readonly string[] }   // owns：执行体为本片；fixer / resolver 为全部切片的并集
export type ActiveTree = { change: string; changeTree: string; slicePrefix: string } // slicePrefix = `<主 worktree>/.claude/worktrees/flight-<change>-`
export type Deny = { deny: string }

export function normalizePath(p: string): string                      // 绝对 posix 路径去掉 `.`、`..`、重复的 `/`
export function globMatch(path: string, pattern: string): boolean     // 与 slice-gate.py 的 glob_match 同语义：精确 / fnmatch（`*` 可跨 `/`）/ `dir/**` 前缀
export function writeTarget(tool: string, input: unknown): string | undefined // Write、Edit 取 file_path；NotebookEdit 取 notebook_path；其他工具返回 undefined
export function writeVerdict(who: Who, absPath: string): Deny | undefined
export function bashVerdict(role: Role, command: string): Deny | undefined
export function bashUpgradable(role: Role, command: string, commands: readonly string[]): boolean // commands = 门禁 test / lint / typecheck 与各片 verify 中非空的
export function mainSessionVerdict(active: readonly ActiveTree[], tool: string, input: unknown): Deny | undefined
export function spawnVerdict(x: { subagentType: string; originPlugin: string | undefined; model: string | undefined; parentInFlight: boolean }): Deny | undefined
```

规则以 design.md 的 D5、D6、D8、D9 为准。要点：
- **`writeVerdict`**：
  - 先判路径是否在 `who.worktree` 内（规范化后前缀匹配，带 `/` 边界）；
  - 再判相对路径是否匹配任一 `owns`；
  - 评审员一律拒绝。
  - 拒绝理由含角色名（执行体 / 修复体 / 解冲突 agent / 评审员）、「owns」与越界的相对路径或绝对路径。
- **分段**：命令按 `&&`、`||`、`;`、`|`、换行切段。每段跳过前导的 `VAR=val`；遇到 `git` 时跳过全局选项（`-C <p>`、`-c <kv>`、`--git-dir=…`、`--work-tree=…`、`--no-pager`），再取子命令。不需要处理引号里的分隔符：处理不了的形式宁可判「不可免询问」。
- **`bashVerdict`**：拒绝表见 D6。`branch` 只在带删改选项时拒绝；`commit` 只在带 `--amend` / `--no-verify` 时拒绝；全文含 `refs/flight/` 即拒绝；评审员另拒 `add`、`commit`、`rm`、`mv`、`apply`、`am`。
- **`bashUpgradable`**：先过 `bashVerdict`。命令含 `$(`、反引号、`<`、除 `2>&1` 之外的 `>`、或单独的 `&` 后台时，直接 false。之后要求每一段都命中白名单（D6）。
- **`mainSessionVerdict`**：
  - Write / Edit / NotebookEdit 的目标落在任一在飞树（`changeTree` 内，或以 `slicePrefix` 开头）时拒绝，理由含「只读」与 change 名；
  - Bash 命令文本含某个在飞树路径（`changeTree` 或 `slicePrefix`），且含改动类 git 子命令（D6 拒绝表，加上 `add`、`commit`、`rm`、`mv`、`apply`、`am`、`restore`）或 `>` 重定向（`2>&1`、`>/dev/null`、`2>/dev/null` 除外）时拒绝；
  - 其余返回 undefined。
- **`spawnVerdict`**：见 D9，三条拒绝理由分别含「控制面」「model」「不得再派发」。
