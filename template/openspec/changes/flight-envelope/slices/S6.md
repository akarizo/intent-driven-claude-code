# S6 · 包络接入引擎事件：tool.call / tool.check / agent.spawn，加在飞集合与 agent 归属缓存

## 前置
S3 已合回 `hooks/envelope.ts`，接口签名见 `slices/S3.md`；S4 已合回 `orchestrator.tsx` 的续飞改动。先读 `slices/_interfaces.md`。

## 做什么

### `template/plugins/flight/hooks/io.ts`
1. **在飞集合**：`export const active: Map<string, ActiveTree>`（`ActiveTree` 从 `./envelope` import）。只在 `appendEvent` 成功写入之后维护：
   - takeoff → `set(f.change, { change, changeTree: f.changeTree, slicePrefix: worktreePath(f, '') })`；
   - land / halt → `delete(f.change)`。
2. **agent 归属缓存**：`appendEvent` 成功写入 dispatch 事件时，记下 `agentId → { change, role, slice, worktree }`。另外导出一个按 agentId 查归属的函数：缓存未命中时退回 `flightOfAgent` 扫账本，并把结果写回缓存。

### `template/plugins/flight/hooks/orchestrator.tsx`
`$` 只能在这个文件里用，策略全部调用 `envelope.ts`。

3. **`tool.call`**，matcher 为 `{ tool: ['Write', 'Edit', 'NotebookEdit', 'Bash'] }`：
   - **有 agentId 且属于在飞飞行**：
     - 写工具用 `writeTarget` 取目标，规范化后交给 `writeVerdict`；
     - Bash 交给 `bashVerdict`；
     - 拒绝时返回 `{ deny }`，否则 `next(e)`。
     - owns 取自该飞行 change 目录的 `slices.json`，可按 change 缓存：执行体用本片 owns，修复体与解冲突 agent 用全部 owns 的并集。
   - **没有 agentId（主会话）**：`mainSessionVerdict([...active.values()], e.tool, e)`。
   - **其余情况**：`next(e)`。
   - **`.catch`**：`next` 已调用就 `next(e)`；否则，如果 agentId 属于缓存里的飞行 agent，就拒绝（「flight：包络判定出错」），其余 `next(e)`。
4. **`tool.check`**，不带 matcher，全插件只有这一个：
   - 先 `const v = await next(e)`。按 design D7：只对飞行 agent、只在 `v.decision === 'ask'` 且 `e.ceiling !== 'ask'` 时，才在包络内改答 `{ decision: 'allow', reason: 'flight 包络内' }`。
   - 包络内指以下几种：
     - Read / Grep / Glob；
     - `writeVerdict` 放行的写入；
     - `bashUpgradable` 为 true 的 Bash（commands 取自 `slices.json` 的 gate 与各片 verify）；
     - 评审员调用 `mcp__flight__submit_findings`。
   - 其余一律原样返回 `v`。
   - `.catch(() => ...)` 原样交回引擎判定：拿不到 `v` 时返回 `{ decision: 'ask' }`，不放行。
5. **`agent.spawn`**：
   - 用 `spawnVerdict({ subagentType: e.subagentType, originPlugin: next.origin?.plugin, model: e.model, parentInFlight })` 判；`parentInFlight` = `e.parentAgentId` 属于在飞飞行的 agent。
   - 拒绝时返回 `{ deny }`，否则 `next(e)`。
   - `.catch`：`next` 已调用就 `next(e)`；否则 `flight:*` 拒绝，其余 `next(e)`。
