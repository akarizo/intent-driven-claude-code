# S3 · io.ts：按 agent 找飞行只靠账本；删除收 $ 的函数；CAS 测试加强

## 做什么
`template/plugins/flight/hooks/io.ts`（3a S5 写的，先读一遍）：

1. **`flightOfAgent(io, agentId)` 签名不变**（`orchestrator.tsx` 已在调用）：
   1. 先查 `flights` 缓存，逻辑与现在相同；
   2. 未命中时：
      - `io.run(['git', 'for-each-ref', '--format=%(refname)', 'refs/flight/'])`（不传 cwd，即会话 cwd），取 `refs/flight/<change>/ledger` 形式的 ref，得到 change 名；
      - `trees(io, '.')`：第一项为主 worktree；`judgesDir(io, 主 worktree)` 得到 hooksDir；
      - 用一个只含 change / mainTree / hooksDir 的临时 Flight，在主 worktree 上读账本：`readLedger` 需要 changeTree 与 changeDir，先用主 worktree 加探测到的 changeDir（`template/openspec/changes/<change>` 或 `openspec/changes/<change>`，取存在的；都不存在就跳过该 change）；
      - 账本里最新 takeoff 的 attempt 已 land / halt，或没有 takeoff → 跳过；
      - 找 dispatch 事件 `agent === agentId`；
      - 找到后重建完整 `Flight`：changeTree 为分支等于 `takeoff.branch` 的 worktree（找不到就用主 worktree）；branch、model 取 takeoff；session 取 `takeoff.by.session`。写入 `flights` 缓存，返回 `{ flight, events }`。
   3. 找不到 → `undefined`。
2. **删除 `ioOf($)` 与 `spawnAgent($, …)`**：`$` 不能跨 import（实测 X12），它们没有、也不可能有调用方。`agentType` 保留，`orchestrator.tsx` 在用。删除后 import 列表里不再需要 `EngineInterface` 的话，一并清掉。
3. **CAS 测试加强**（io.test.ts 的 `io-appends-event-with-cas-retry` 不改断言，新增一个测试）：假 Io 的 `rev-parse` 按调用次数返回 T1、T2。断言：
   - `rev-parse` 调了 2 次；
   - 第二次 `commit-tree` 的参数含 `['-p', T2]`；
   - 两次 `update-ref` 的旧值依次为 T1、T2。

   `appendEvent` 的实现本来就在循环内重读链尾，正确；这一步只补测试。
