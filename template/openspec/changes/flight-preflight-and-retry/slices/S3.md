## 契约

```js
const startCmd = (s, base) => `python3 ${hooksDir}/slice-gate.py start ${s} --change-dir ${changeDir}` + (base ? ` --base ${base}` : '')
// GATE.properties 加 base: { type: 'string' }（不进 required）
// executorPrompt(s, retryOf)：
//   retryOf 为空 → 第零步 expectHead 校验（原文不变）
//   retryOf 非空 → 第零步：`git rev-parse HEAD` 不等于 ${retryOf.commit} 则 `git cherry-pick ${retryOf.commit}`；
//                  冲突 → `git cherry-pick --abort` 并返回 {"slice":"S","ok":false,"commit":"<HEAD>","failed":["G0 base: cherry-pick <sha> 冲突"]}
//                  第一步：startCmd(s, retryOf.base)
```

- `slice-executor.md` 开工段第 2 条补一句：重派时 prompt 会给上一轮 commit 与 `--base`，按 prompt 的第零步先接上再 `start`；`start` 对同片幂等。
- `opsx-apply.md` step 3 在 `lint` 命令后加 `python3 .claude/hooks/slice-gate.py preflight --change-dir openspec/changes/<name>`：非 0 → 停下报告 stderr（缺基线 / 基线红 / 过期），不进入实现。step 5 回退路径把「门禁红则以其 `failed` 重派同一切片一次」扩成「重派 prompt 带上一轮 `commit` 与 `base`：HEAD 不是它则 `git cherry-pick`，再 `start <S> --base <base>`」。`openspec-apply-change/SKILL.md` 同句同改。
