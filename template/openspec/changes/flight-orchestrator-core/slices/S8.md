# S8 · 评审回收与落地接线：submit_findings、评审员与修复 agent 收口、final、落地接 /pr-ship、停飞

## 做什么
把 S5 留下的空壳 `template/plugins/flight/hooks/landing.tsx` 换成实现，导出不变：
- `registerLanding(on: On): void`
- `runLandingAction($: EngineInterface, f: Flight, action: Action): Promise<void>`

### 1. 评审回收工具
- `session.start`：`$.tool.register({ name: 'submit_findings', description: <说明：只有本次飞行派发的评审员能用；没有问题也提交空列表>, inputSchema: { type: 'object', properties: { findings: { type: 'array', items: {...severity/file/line/summary/fix} } }, required: ['findings'] }, isDeferred: false })`，然后 `next(e)`。
- `tool.call`（matcher `{ tool: 'mcp__flight__submit_findings' }`）：
  1. `flightOfAgent(io, e.agentId)`；
  2. 找不到、role 不是 reviewer、或不是当前 attempt → `{ deny: '只有本次飞行派发的评审员可以提交 findings' }`；
  3. `validateFindings({ findings: e.findings })` 不过 → `{ deny: '校验失败：<error>' }`；
  4. 通过 → 追加 review 事件（slice、agent、findings），返回 `{ result: 'findings 已记录：<n> 条' }`（必须是字符串，实测）。
  
  加 `.catch(($, e, next) => next.called ? next(e) : { deny: 'flight：评审回收失败' })`。这个工具只能写 review 事件。

### 2. 收口（`classic.SubagentStop`）
- `flightOfAgent` 找不到 → `next(e)`。
- **reviewer**：账本里没有它的 review 事件，且本模块还没提醒过它 → 记入已提醒，`block` 文本含 `submit_findings` 与「空列表」；否则 `next(e)`。
- **fixer**：
  1. 在 dispatch 记录的修复 worktree 里 `judge slice-gate final --change-dir <changeDir>`（timeout 600000）；
  2. 解析 JSON，记 gate 事件（slice 为 fix，含 agent）；
  3. `stopVerdict` 判 block 或放行。
- **其他 role** → `next(e)`。它们归 S7。

### 3. `runLandingAction`（S7 的 drive 调用）
| 动作 | 执行 |
|---|---|
| dispatch reviewer | cwd 为 `f.changeTree`；`spawnAgent(role reviewer, reviewerPrompt({ commit }))`；记 dispatch（slice S，worktree 为 changeTree）；被拒 → 记 blocked（`review:<S>`、infra）。 |
| dispatch fixer | `ensureWorktree(f, 'fix')`；`spawnAgent(role fixer, fixerPrompt({ findings }))`；记 dispatch（slice fix）。 |
| final | 在 changeTree 里 `judge slice-gate final --change-dir <changeDir>`（timeout 600000），记 final 事件（ok / commit / failed）。 |
| land | `closeoutLists(reduce(events))`；merged 取已合回切片；`closeout(io, f, lists, merged)`；记 land（verdict）；`$.ui.status(undefined)`；最后 `$.command.run({ command: 'pr-ship', args: f.change })`。`$.prompt.submit` 不能提交斜杠命令（实测 X10）。 |
| halt | 记 halt；`$.ui.status(undefined)`；`$.ui.toast('flight：<change> 停飞：<reason>')`；不运行 pr-ship。 |
