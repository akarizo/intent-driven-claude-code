## 做什么（`template/plugins/flight/hooks/envelope.ts` 的 `spawnVerdict`，design D6）
`subagentType === 'flight:code-reviewer'` 的派发：

| 情况 | 结果 |
|---|---|
| 来源不是 `flight` | 不再按「flight:* 只能由 flight 控制面派发」拒绝 |
| 没有 `model` | 照旧拒绝「派发须显式指定 model（铁律 11）」 |
| `parentInFlight` 且来源不是 `flight` | 照旧拒绝「飞行中的 agent 不得再派发子 agent」 |

其他 `flight:*` 类型的判定不变。

建议写法：把例外放成一个常量，例如 `const MAIN_SPAWNABLE = ['flight:code-reviewer']`，注释写明它供 `/flight:pr-ship` 的评审由主会话派发。
