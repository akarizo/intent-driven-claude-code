## 契约

```text
slice-gate.py checkpoint
  stdin: hook 载荷 JSON（取 "cwd"；空 / 非法 → 用进程 cwd 或直接退出）
  有标记 → owns = slices.json 里该片 owns；files = `git status --porcelain -uall` 路径 ∩ owns（排除 .openspec-slice 与 change 目录前缀）
        → files 为空且 HEAD == marker.base → 不写
        → 否则 GIT_INDEX_FILE=<独占临时文件>：read-tree HEAD → add -A -- files → write-tree → commit-tree -p HEAD -m "flight checkpoint <S>"
        → update-ref refs/flight/<basename(change_dir)>/<S> <sha>
  stdout 永远为空；整个子命令 try 包住，任何异常 exit 0；临时 index 用完删除

slice-gate.py start S --change-dir D [--base B] [--expect-branch BR] [--resume-checkpoint]
  既有：切片存在校验 → --expect-branch 校验（失败打印 G0 JSON、exit 1）→ 同片标记 → resume（不动快照）
  新：无同片标记时
    --resume-checkpoint 且 ref 存在且 `merge-base --is-ancestor HEAD <snap>` → 恢复：
        diff --name-only HEAD <snap> ∩ owns；快照中存在 → `git checkout <snap> -- f`；不存在 → 删工作区文件
        timeline 备注 "<S> (checkpoint N files)"
    --resume-checkpoint 但 ref 不存在 / 基点不符 → 不恢复，note 说明
    不带 --resume-checkpoint → 写标记前 `update-ref -d` 本片 ref（忽略不存在）
  stdout = 标记 JSON；带 --resume-checkpoint 时追加 "checkpoint": {"restored": [...], "note": "..."}（restored 为空时 note 必填）

slice-gate.py gate S ...
  result.ok 为真（删标记那一处）→ 同时 `update-ref -d` 本片 ref（忽略失败）
```

引用名：`refs/flight/<os.path.basename(marker.change_dir 或 args.change_dir)>/<S>`；测试里 change 目录名是 `c`，即 `refs/flight/c/S1`。

## 坑

- ⚠ 快照与恢复都**不得**改真实 index / HEAD（恢复时 `git checkout <snap> -- f` 会写真实 index，这是允许的——恢复本来就要把文件放回工作区；快照路径则只许动临时 index）。
- ⚠ 临时 index 要放在本进程独占的路径（如 `tempfile.mkstemp`），并行工具调用会并发触发 hook。`GIT_INDEX_FILE` 只设给子进程 env，别改本进程全局 env。
- ⚠ worktree 里 `.git` 是文件不是目录；不要拼 `.git/index` 路径，用临时文件即可。
- ⚠ `checkpoint` 不加进 `("lint", "waves", "final", "baseline", "preflight")` 那组（它不需要 `--change-dir`）。
- ⚠ 既有 `test_start_keeps_marker_for_same_slice` / `test_start_accepts_base_flag` / `test_start_expect_branch_*` 必须继续通过：不带新参数时 stdout 仍只是标记 JSON。
- ⚠ 每条新测试解锁时去掉 `@pytest.mark.xfail(strict=True, ...)` 那一行。
