# S2 · phase-gate.py：explore 阶段越界 deny

**目标**：explore 阶段不许产出飞行计划工件、不许跑 baseline——从"模型自觉打住"变成 hook 判定。

## owns

- `template/.claude/hooks/phase-gate.py`（新建）
- `tests/test_phase_gate.py`（骨架已在，去掉 xfail 标记即解锁）

## 事实基线（已对官方文档 + 本机 2.1.269 验真，不要再猜）

- **hook 能力**：`PreToolUse` 支持 `permissionDecision: "allow" | "deny"`；`SubagentStart` **不能阻断**（"Exit code 2 isn't honored"）——不要试图用它拦执行体。
- **hook 输入**：公共字段含 `session_id` · `transcript_path` · `cwd` · `hook_event_name`；`PreToolUse` 另有 `tool_name` · `tool_input` · `tool_use_id`。
- ⚠ **转录是异步写入的**，官方文档原话："may not yet include the current turn's most recent messages when a hook fires"。因此**只读"更早的、已落盘的"人类命令消息**来判阶段，不要依赖当前这一轮的消息已入转录。
- **转录里的人类命令消息**形如 `<command-message>opsx-explore</command-message> <command-name>/opsx-explore</command-name> <command-args>…</command-args>`；人类消息形状识别（`isMeta` / `isSidechain` / `userType` / 非 `tool_result`）与 `takeoff-gate.py` 同源。
- **不重复实现**：派实现类子 agent 的拦截由 `takeoff-gate.py` 覆盖（S1），本切片不碰派发。

## 契约

```
python3 .claude/hooks/phase-gate.py        # 只从 stdin 收 hook JSON，无 CLI 子命令
```

只处理 `hook_event_name == "PreToolUse"`，其余事件静默放行。

1. 从转录取**最后一条人类命令消息**里的 `/opsx-<x>` 作为当前阶段；取不到 → 静默放行。
2. 阶段 != `explore` → 静默放行。
3. 阶段 == `explore` 时判越界：
   - `tool_name` 属 `Write` / `Edit`，且 `tool_input.file_path` 命中 `openspec/changes/*/` 下的 `slices.json` · `tasks.md` · `slices/*.md` → **deny**。
   - `tool_name == "Bash"`，且 `tool_input.command` 同时含 `slice-gate.py` 与 `baseline` → **deny**。
   - 其余 → 静默放行（`proposal.md` · `design.md` · `specs/**` 必须放行）。
4. deny 输出（与 `intent-gate.py` 同形）：
   ```json
   {"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"deny","permissionDecisionReason":"…"}}
   ```
   reason 点名当前阶段是 explore、该动作属 propose 收口、要显式 `/opsx-propose`。
5. 任何异常一律放行（与 `intent-gate.py` · `takeoff-gate.py` 同规矩）；坏行跳过不崩。

只读，不改任何文件。兼容 Python 3.8+，只用标准库。
