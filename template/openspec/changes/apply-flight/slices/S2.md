# S2 · 留痕与飞行记录

**目标**：测试运行由 hook 留痕；飞行事件可记录可报告；切片未过门禁不许收口；收口能分解会话。

## 产物（owns）

- `template/.claude/hooks/test-evidence.py`（新）：stdin 读 PostToolUse / PostToolUseFailure JSON；`tool_name == "Bash"` 且命令匹配 `pytest|npm (run )?test|pnpm (run )?test|yarn test|vitest|jest|go test|cargo test|make test|tox|unittest` 时，向 `<change_dir>/evidence.log` 追加 `ISO时间\t<slice或->\t<PASS|FAIL>\t<命令前120字符>`。结果判定：事件名为 PostToolUseFailure → FAIL；否则看 `tool_response.stdout/stderr` 是否含 `failed|error|FAIL`（大小写不敏感）→ FAIL，其余 PASS。change_dir 来源：git toplevel 下 `.openspec-slice` 的 `change_dir`；没有标记则找 `openspec/changes/*/tasks.md` 仍有未勾选项的 change；都没有则静默退出。fail-open。
- `template/.claude/hooks/timeline.py`（新）：`record <event> --change-dir DIR [--note TEXT]` 追加 `ISO时间\t<event>\t<note>` 到 `timeline.md`（首次创建带表头注释）；`report --change-dir DIR` 打印事件表与 `approve → pr-open` 分钟数（缺任一事件则打印 `n/a`）。提供可导入函数 `record(change_dir, event, note="")`。
- `template/.claude/hooks/stop-gate.py`（新）：stdin 读 Stop / SubagentStop JSON；若 `stop_hook_active` 为 true → 直接退出；否则在 `cwd` 的 git toplevel 找 `.openspec-slice`，存在即输出 `{"decision":"block","reason":"切片 <S> 已 start 但门禁未绿：运行 python3 .claude/hooks/slice-gate.py gate <S> --change-dir <dir>，绿后再收口"}`。找不到标记则静默。fail-open。
- `template/.claude/hooks/session-decompose.py`（新）：合并本 change 分析用的三份脚本。`--session PATH`（主转录 jsonl）；按「终结空隙的事件」归因：assistant → 模型生成；tool_result（非 Agent）→ 工具执行（AskUserQuestion → 等人）；`<task-notification>` → 等子 agent；人类消息 → 等人；读同目录 `<session-id>/subagents/agent-*.jsonl` 统计子 agent 数、角色（impl / review / fix / other，按 description 关键词）、均 wall、均轮次；打印一张紧凑表。无子 agent 目录时只打印主会话部分。
- `template/.claude/hooks/hooks.json`（改）：新增 `PostToolUse` 与 `PostToolUseFailure` 的 `Bash` matcher → test-evidence；新增 `Stop` 与 `SubagentStop` → stop-gate；保留现有三项。
- `template/.claude/settings.json`（改）：增加 `"worktree": {"baseRef": "head"}`；env 保留。
- `tests/test_evidence_timeline.py`（新）

## 验证

`python3 -m pytest -q tests/test_evidence_timeline.py`：用 tmp 目录 + `git init` 构造 `.openspec-slice`；用 subprocess 喂 stdin JSON；session-decompose 用手写的 6 行 jsonl fixture。
