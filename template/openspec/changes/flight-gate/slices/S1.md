## 契约

### 分类（新增，判据核心）

对一条人类消息文本分类：

| 类别 | 判据 |
|---|---|
| **发起** | 含 `<command-name>/opsx-apply`·`/opsx-bulk-apply`，**或** 含该 change 名，**或** 含 `openspec/changes/<name>` / worktree 路径片段 |
| **确认** | 整条 ≤ `WORD_LIMIT` 字 · 含批准词 · **且不含** change 名与路径片段 |
| 其它 | 都不是 |

先判发起再判确认——含 change 名的长指令即使带批准词也是发起。

### 判定

取转录里**最后一条人类消息**：

- 是**确认**，且其时间 ≥ 发起消息时间、≥ 计划工件最大 mtime → **批准成立**，exit 0，stdout 打印批准证据（时间戳 + 原话摘要）。
- 是**发起** → `EXIT_NO_APPROVAL`，输出停下信息（下方）。
- 其它 / 无 → `EXIT_NO_APPROVAL`，沿用既有措辞。
- 确认早于发起（上一轮遗留）→ 不成立。

### 停下时的输出（CLI stderr 与 hook 的 `permissionDecisionReason` 用同一段文本）

一次给全，人不必再问：

- 当前主模型别名 + 一句"executor / reviewer 会用它"。**判不出别名（第三方 id / 读不出 assistant）→ 仍然停下**并点名原因（fail-closed）。
- 切片数与 wave 数（读 `slices.json` 的 `slices` 与 `deps` 拓扑分层；读不到就省略该项，**不因此失败**）。
- 该 change 的 worktree **绝对路径**（从 `change_dir` 向上找含 `.git` 的目录）与 `spec.html` 绝对路径。
- 补救指引：确认无误回一句 `起飞`；要换模型先 `/model` 再回。

### 不变

- 人类消息形状识别（`isMeta` / `isSidechain` / `userType` / 非 `tool_result` / 非 `<local-command-stdout>` 等）原样保留。
- hook 模式只判起飞类派发（`Workflow` 带 `args.changeDir` / `Agent`·`Task` 派 `slice-executor`·`integrator`）；无关派发、脚本异常、转录不可读一律**放行**。
- CLI 有参数走 CLI、无参数走 hook 的入口结构不变。
