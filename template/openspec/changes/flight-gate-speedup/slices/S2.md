## 做什么
全部在 `template/.claude/hooks/slice-gate.py`：

1. **`final --reuse-fix`（D3）**：
   - 子命令 `final` 增加开关 `--reuse-fix`；
   - 开启时：`import ledger`（同目录，与 `takeoff-gate.py` 一样），`ledger.read_events(change_dir)`，取最后一条 `ev == "gate"` 且 `slice == "fix"` 的事件；
   - `ok is True`、`commit` 非空、且 `_final_fresh(root, change_dir, commit)` 为真 → 跳过 G2，warnings 追加「G2 test: 复用修复门禁 <commit 前 10 位> 的全量结论（其后只有记账改动）」，JSON 加 `"reused": <commit>`；
   - 否则照常跑 G2；读账本抛 `ledger.LedgerInvalid` / `ledger.LedgerUnreadable` / `OSError` → 照常跑，并在 warnings 记一行原因；
   - G7 红时仍按 S1 不跑 G2，复用判断只在 G7 无违规时才有意义；
   - 不带开关时行为与 S1 完全一致。
2. **baseline 运行标记（D5）**：`cmd_baseline` 在跑任何命令之前，把 `gate-baseline.json` 写成 `{"running": true, "pid": os.getpid(), "started": now_iso()}`；结束时照旧整体覆盖为最终结果（不含 `running`）。
3. **preflight 识别标记（D5）**：`cmd_preflight` 在 lint 之后、现有四项校验之前，如果 `bl.get("running") is True`：
   - pid 存活（`os.kill(pid, 0)` 成功或抛 `PermissionError`）→ die「基线仍在跑（已 X 分钟，上次全量约 Y 秒）：等它结束再起飞」，Y 取 `slices.json` 的 `gate.full_suite_sec`，没有就写「未知」；
   - `ProcessLookupError` 或 pid 不合法 → die「基线中断（进程 <pid> 已不在）：重跑 slice-gate.py baseline --change-dir <dir>」。
4. **`gate.test` 必填（D5）**：`lint_plan` 在 `(data.get("gate") or {}).get("test")` 为空或全空白时追加错误「gate: gate.test 缺失（须显式写出，baseline 不再自动探测写回，避免改动计划指纹）」。
5. 文件头注释：`final` 一行补 `[--reuse-fix]`；`baseline` 与 `preflight` 两行写明运行标记。
