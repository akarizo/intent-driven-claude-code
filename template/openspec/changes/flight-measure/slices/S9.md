## 做什么

### 1. `template/plugins/flight/hooks/envelope.ts`
- **eval 换目录回传外层**：`eval` 在当前 shell 执行，所以内层的 `cd`、`pushd`、`popd` 设定的目录要回传给外层后续各段。`bash`、`sh`、`zsh -c` 在子进程执行，外层目录不受影响。
- **外层 GIT_* 进内层**：段首（含经 `env` 给出的）`GIT_*` 赋值键名，要与内层各段自己的键名合并后再判定。内层改动类 git 见到合并后的 `GIT_*` 就拒绝，只读 git 不拒。
- **前缀选项带参数**：
  - `env` 不带参数的已知选项（`-i`、`-0`、`-v`、`--ignore-environment`、`--null`、`--debug`）剥掉；
  - 带参数的选项连同参数一起剥掉：env 的 `-u` / `--unset`、`-C` / `--chdir`、`-S` / `--split-string`、`-P`，以及 exec 的 `-a`，同时支持 `--opt=val` 写法；
  - `env -C <p>` 与 `--chdir=<p>` 按 `cd <p>` 设定目录；
  - 剥前缀时遇到不认识的 `-` 选项 → 拒绝，理由含「无法判定」。

### 2. `template/.claude/hooks/slice-gate.py`
