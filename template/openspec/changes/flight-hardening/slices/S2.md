# S2 · 落地与停飞打印飞行记录；派发修复 agent 前提交记录；事件校验只认字段表自己的键

## 做什么
1. **`core.ts`**：`Ctx` 加一个闭包 `log(text: string): Promise<void>`（打印到转录；其余字段不动）。
2. **`orchestrator.tsx` 的 `ctxOf($)`**：只加一行 `log: async text => $.ui.log(text)`，本文件的其他部分归 S3。插件只能在这一个文件里碰 `$`（实测 X12）。
3. **`landing.tsx` 的 `runLandingAction`**：
   - **land**：记 land 事件、清状态行之后，在 `ctx.runCommand('pr-ship', …)` **之前**，`await ctx.log(record)`。
   - **halt**：记 halt、清状态行、toast 之后，`await ctx.log(record)`。
   - **record 的内容**：
     - 首行：落地时为 `飞行记录 · ${f.change}`；停飞时为 `停飞 · ${f.change}：${reason}`。
     - 正文：`judge(io, f, 'timeline', ['report', '--change-dir', f.changeDir], f.changeTree)` 的 stdout；非 0 时写一行 `（timeline report 失败：<stderr 首行>）`。
     - 末行：`routingFindings(state)`（`core.ts` 已有）为空时写 `路由对账：一致`；否则写 `路由对账：N 条不符`，后接每条的 summary。
   - **dispatch fixer**：`ensureWorktree(io, f, FIX)` 之前先 `const err = await commitRecords(io, f, 'chore(flight): 记录')`（`land.ts` 已导出）。有 err 就记 fix 的 infra 阻断，原因为 `提交飞行记录失败：${err}`，不派发。
4. **`io.ts` 的 `eventProblem`**：取字段表前先判 `typeof e.ev === 'string' && Object.prototype.hasOwnProperty.call(EVENTS, e.ev)`，否则返回 `'ev 非法'`。

## 约束
- 打日志永远不能拖垮飞行：`ctxOf` 的 `log` 写成 `try { $.ui.log(text) } catch { /* 打印失败不影响飞行 */ }`。`orchestrator.test.tsx`（归 S3）现有测试走真实的 `ctxOf`，测试世界没有 mock `ui.log`，这样写也保证它们保持绿。
- `landing.tsx` 不碰 `$`、不 import `claude-code` 的运行时值。
