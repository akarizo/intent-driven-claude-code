# S5 · 批准带去重

## 做什么
`template/plugins/flight/hooks/register.tsx` 的 `ui.press`（`approve:`）处理（设计 D9）：
- 在 `serial(() => appendApprove(...))` 的同一个串行段里、追加之前，读一遍账本：
  - 先找到最近一次 takeoff 之后的事件（没有 takeoff 就是全部）；
  - 如果其中最后一条 approve 的 `fp` 等于这次要批准的 `fp`，就不追加，`$.ui.toast(\`flight：${change} 已批准（指纹相同），无需重复按\`)`，然后照常 `refresh` 并结束。
- 读账本复用本文件里 `appendApprove` 已有的读法，不新增写入口。读失败按「不去重」处理：照常追加，不能因为读失败就拒绝批准。
