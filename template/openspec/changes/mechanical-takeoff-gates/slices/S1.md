# S1 · 判定脚本 session-model.py

**目标**：把"当前会话主模型"从模型自述变成脚本判定；判定不出就报错，绝不给默认值。

## owns

- `template/.claude/hooks/session-model.py`（新建）
- `tests/test_session_model.py`（骨架已在，去掉 xfail 标记即解锁）

## 事实基线（实测，不要再猜）

- 主会话转录：`~/.claude/projects/<slug>/<session-id>.jsonl`，每行一个 JSON 对象。
- assistant 条目形如：`{"type": "assistant", "isSidechain": false, "timestamp": "…Z", "message": {"model": "claude-opus-5", …}}`。
- 子 agent 转录**不在**主转录里（另存 `<session-id>/subagents/…`），故主转录里 `isSidechain` 实测恒 `false`；实现仍显式跳过 `isSidechain: true`。
- API 错误占位条目的 `message.model` 为 `<synthetic>`，必须跳过。
- 真实出现过的 id：`claude-opus-5` · `claude-opus-5[1m]` · `claude-fable-5-1` · `claude-fable-5-1[1m]` · `claude-sonnet-5` · `k3`（第三方，**不可映射**）。
- `CLAUDE_CODE_SESSION_ID` 实测存在于 Bash 工具环境（本机 2.1.267）。

## 契约

```
python3 .claude/hooks/session-model.py [--session PATH] [--json]
  stdout  别名之一：opus | sonnet | haiku | fable（--json：{"alias","model","session","source"}）
  exit 0  判定成功
  exit 3  判定失败，stderr 一行点名原因
```

- 定位顺序：`--session` > `CLAUDE_CODE_SESSION_ID` glob `~/.claude/projects/*/<sid>.jsonl`；**不按 cwd 推 slug**（D2）。
- 取值：从文件末尾向前找第一条 `type == "assistant"` 且 `isSidechain` 非真、`message.model` 非空且非 `<synthetic>` 的条目。
- 映射：模型 id 小写后按子串命中 `opus` / `sonnet` / `haiku` / `fable` → 同名别名（`[1m]` 变体自然归基座）。命中不了 → 失败，stderr 带原始 id。
- **公开函数 `alias_of(model_id) -> str | None`**：S2 会以 `importlib` 按路径加载本文件调用它，签名不要改名。
- 坏行（非法 JSON）跳过即可，不因单行崩溃。
