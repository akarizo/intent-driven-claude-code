## 做什么（新模块 `template/plugins/flight/hooks/abort.ts`，design D3）
```ts
import type { State } from './core'

export async function abortFlight(x: {
  state: State
  session: string
  halt: (reason: string) => Promise<boolean>
  live: () => Promise<string[]>
  stop: (agentId: string) => Promise<string | undefined>
}): Promise<string>
```
- **纯逻辑**：不 import 运行时 API，副作用全经三个回调。
- **处理顺序**：
  1. `state.takeoff` 不存在，或本 attempt（`state.attempt`）已有 land 或 halt 事件：返回含「没有在飞的 attempt」的文本，不调用任何回调。
  2. `state.takeoff.by.session` 与 `x.session` 不同：返回含「另一个会话（<前 8 位>）」与「到那个会话里 /flight abort」的文本，不调用任何回调。
  3. 调用 `halt('人工中止（/flight abort）')`。返回 false 时，返回含「记停飞失败，未停任何 agent」的文本。
  4. `ids = await live()`，逐个 `await stop(id)`：返回 `undefined` 记为「已停」，否则记为「未停（<原因>）」。没有 id 时写「没有在飞的 agent」。
  5. 回复依次为：首行「已中止 <change> attempt <n>（已在账本记停飞）」，每个 agent 一行，末行提示「未提交的改动留在各自 worktree；可用 /flight resume <change> 续飞」。
- `<change>` 取自 takeoff 事件的 `change`。
