# S2 · hooks.json 注册 + explore / apply 命令与 skill 同改

**目标**：把 S1 的脚本挂上去，并把它的边界写进人读得到的命令文本——命令与 hook 判据同改，禁漂移。

## owns

- `template/.claude/hooks/hooks.json`
- `template/.claude/commands/opsx-explore.md`
- `template/.claude/commands/opsx-apply.md`
- `template/.claude/skills/openspec-explore/SKILL.md`
- `template/.claude/skills/openspec-apply-change/SKILL.md`
- `template/.claude/commands/opsx-propose.md`
- `template/.claude/skills/openspec-propose/SKILL.md`
- `tests/test_template_docs.py`（骨架已在，去掉 xfail 标记即解锁；文件里其它测试不要动）

## 依赖 S1 的接口

`template/.claude/hooks/phase-gate.py`，只从 stdin 收 hook JSON，无 CLI 子命令；靠 `hook_event_name` 区分 `PreToolUse` 与 `UserPromptSubmit` 两种模式。注册时两条都指向同一个脚本，无需传参。

## 要做的改动

### 1. `hooks.json`（hook 唯一真源，`install.sh` 幂等合并进目标 `settings.json`，**不要改 `settings.json`**）

- `PreToolUse` 追加一条：`"matcher": "Write|Edit|Bash"` → `python3 "$CLAUDE_PROJECT_DIR/.claude/hooks/phase-gate.py"`。
- `UserPromptSubmit` 追加一条：同一脚本（该事件无 matcher）。
- 既有三条（`intent-gate` 的 `Write|Edit`、`takeoff-gate` 的 `Workflow|Agent|Task`、`intent-reminder`）原样保留，顺序不变。

### 2. `opsx-explore.md` + `openspec-explore/SKILL.md`

Guardrails 增三条硬边界（两份文件措辞一致）：

- 不产出飞行计划工件：`slices.json` · `tasks.md` · `slices/*.md`。
- 不跑 baseline（`slice-gate.py baseline`）。
- 不派实现类子 agent（`slice-executor` · `integrator`）。
- 工件成形后**引导人显式 `/opsx-propose`**，不在同一轮继续。

同时保留既有定位：`proposal.md` · `design.md` · `specs/**` 仍可在 explore 内写。**删掉**"Ending Discovery → Flow into a proposal"里把 explore 直接推进到飞行的措辞（改成"交回给人，由人敲 `/opsx-propose`"）。

### 3. `opsx-apply.md` + `openspec-apply-change/SKILL.md`

- **Input** 段写明：`--confirm-model=<alias>` 是起飞确认 flag，**不参与 change 名解析**（解析 change 名时跳过所有 `--` 开头的 token）。
- **step 0** 在既有 `takeoff-gate.py` 自检之外补一句：该 flag 由 `UserPromptSubmit` hook 强制，**命令自身不判断、不重复校验**；第一次敲 `/opsx-apply` 被拦下是设计而非故障。
- 既有的 `takeoff-gate.py` 自检与 `session-model.py` 取 `<main>` 的步骤**原样保留**，不要改写。

### 4. `opsx-propose.md` + `openspec-propose/SKILL.md`——收尾交付一段自足的起飞指令

现状是收尾只打印 `spec.html` 绝对路径 + 一句"请你自己发出 `/opsx-apply <name>`"。人切模型起飞要先 `/clear`，清空后既不知道在哪个目录，也不知道派发参数——**硬交接的"三件事"改为四件**，新增一段**可直接复制的起飞指令**：

- worktree 的**绝对路径**（用 `pwd` 拼，不写相对路径）。
- change 名与 `--confirm-model=<alias>` 占位（alias 由人起飞时按实际主模型填）。
- 派发参数：`changeDir` · `hooksDir` · `agentsDir` · `waves` · `deps` · `expectHead`（`git rev-parse --short=10 HEAD`）。
- ⚠ 路径前缀按**本仓实际布局**拼，不要硬编码：模板开发仓是 `template/openspec/changes/<name>` · `template/.claude/hooks`；安装后的目标仓库是 `openspec/changes/<name>` · `.claude/hooks`。

既有三件事（`spec.html` 绝对路径 · 本命令到此结束 · 工件单独 commit）**原样保留**。
