## 做什么

### `template/plugins/flight/hooks/armed.ts`
`relaunch`（约第 124 行）的 resume 分支，现在只给出 `/flight resume <change>`。改为带上 `arm.args` 里 change 名之外的参数（如 `--takeover`）；非 resume 分支保持 `/opsx-apply <原参数>`。

### `template/plugins/flight/hooks/land.ts`
`commitArtifacts`（约第 56 行）现在读 `git status --porcelain -- <abs…>`，按行 `slice(3)` 取路径。改为：
- 读 `git status --porcelain -z -- <abs…>`，按 `\0` 切成条目；
- 条目形如 `XY <path>`；改名 / 复制（X 为 `R` 或 `C`）的条目后面跟一个原路径条目，要跳过；
- XY 为 `D ` 的路径不交给 `git add`；
- 路径与传入的相对路径逐字比对，不再受 `core.quotePath` 影响。

其余行为不变：status 失败时照旧对全部路径 add；全部都是已暂存删除时不调用 add。
