# S4 · 新引擎 final 动作带 --reuse-fix，修复体收口门禁不带；插件补丁版本 +1

先读 `design.md` 的 D3、D7。`--reuse-fix` 的判定由 S2 在 `slice-gate.py` 里实现；本片只改插件的调用参数，测试用假 io。

## 做什么
1. `template/plugins/flight/hooks/landing.tsx`：
   - `runFinal(io, f, cwd)` 增加一个参数（例如 `opts?: { reuseFix?: boolean }`），为 true 时 argv 追加 `--reuse-fix`；
   - `runLandingAction` 的 `final` 分支改为 `runFinal(io, f, f.changeTree, { reuseFix: true })`；
   - `onLandingStop` 的修复体分支保持不带该参数。
2. `template/plugins/flight/.claude-plugin/plugin.json` 的 version 在你的 worktree 当前值上升一个补丁号（例如 0.3.2 → 0.3.3；若 `flight-measure` 已先合入、当前为 0.4.0，则 → 0.4.1）。
