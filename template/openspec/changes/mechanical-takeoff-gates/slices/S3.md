## 逐文件改法

### `template/.claude/commands/opsx-apply.md`（与 apply skill 同改）

1. **新增 step 0「批准自检」**（在选 change 与 git 纪律检查之前或紧随其后）：跑 `takeoff-gate.py --change-dir …`；`exit 0` → 把 stdout 的批准证据留着给 step 4；`exit ≠ 0` → **停下报告**，打印 `spec.html` 绝对路径，说明"起飞需要你自己发出 `/opsx-apply <change>`"，**不进入任何后续步骤、不派发**。
2. **路由表**：executor / reviewer 两行的模型列改为 `会话主模型别名 <main>（由 session-model.py 判定，见 step 5）`——删掉 `看 /model` 这种自述式判定。
3. **Input 段**：新增 `--model=<alias>` 旗标说明（人工覆盖，优先于脚本；用于判定不出或主模型是第三方 id 时）。
4. **step 4**：`timeline.py record approve --note "<批准证据>"`；`.flight` 内容改为 `{"started","approval","models","efforts","raw","source"}`。
5. **step 5 首行**：`<main>` 由 `session-model.py` 判定；`exit ≠ 0` → 停下报告，提示 `--model=<alias>`。
6. **step 6 收口**：`session-decompose.py … --expect-models '<.flight 里的 models>'`；非 0 → 铁律 11 违规：收口报告点名不符 agent，并让 `/pr-ship` 以 **draft** 建 PR（与 final 未绿同处置）。
7. **Guardrails**：补两句——「起飞前的人类批准由 `takeoff-gate.py` 校验，禁模型自证」「`<main>` 由 `session-model.py` 判定，禁模型自述」。
8. 两处"停下报告"都不是 `AskUserQuestion`（`test_apply_command_zero_prompts` 会数），措辞用"停下报告"。
