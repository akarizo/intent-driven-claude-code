## 做什么（design D1、D4）

### `template/.claude/hooks/slice-gate.py`
- **删除子命令** `start`、`record`：删掉 argparse 定义、`cmd_start`、`cmd_record`，以及只为它们服务的函数（如 `report_has_row`）。
- **新增子命令 `base`**：形状见 `slices/_interfaces.md`。
  - 实现可复用 `load_plan` 与 `_base_check`；
  - 不调用 `timeline_record`，不写标记，不写任何文件。
- **`gate` 与 `measure`**：
  - `--base` 改为 `required=True`；
  - 删掉「缺 `--base` 时读标记」与「门禁绿时删标记」。
- **`gate`、`final`、`baseline` 不写记录**：
  - 删掉对 `append_report`、`record_ceilings`、`timeline_record` 的调用；
  - 这三个函数（以及 `ceiling_rows_from_json`）在本文件里不再被引用时一并删除。gate-report 的写法将由 S2 移入 `timeline.py`，S2 会从本片的起点版本照搬格式。
  - `baseline` 照旧写 `gate-baseline.json`。
- **标记退役**：删掉 `.openspec-slice` 的常量、`_read_marker` 等读写函数，以及改动清单里对标记文件名的排除项。`BOOKKEEPING`、`FLIGHT_RECORDS` 里的 `timeline.md`、`gate-report.md` 保留。
- **`FEATURES`** 增加 `ledger-records`。
- 文件头的用法注释同步：去掉 start / record，加上 base，并注明 gate / measure 的 `--base` 必填。
- **`checkpoint` 空壳保留**（D3-A）。
