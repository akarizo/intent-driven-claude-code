# S5 · 批准带：三个按钮按下即起飞、「起飞」按钮、停飞判定修正、续飞前停诊断员

依赖 S3：`takeoffNow`（不收 `$`）与类型 `FlightItem.mode` 的 `'takeoff'`。与 S4（待命接线）、S6（文档）并行；本片不改 `orchestrator.tsx`。接口见 `slices/_interfaces.md`。

## 先读：#53 的教训
- **`$` 不出文件**：`register.tsx` 只 `import { takeoffNow } from './orchestrator'` 并直接调用它，任何时候都不把 `$` 传给别的文件的函数（`claude plugin validate` 会拒绝）。插件自己 `$.command.run('/flight resume …')` 也不行：origin 为 plugin，会被 `/flight` 拒。
- **测试与插件是隔离实例**：在测试里 import `takeoffNow` 调用拿到的是另一份模块（闭包没设），必须经按键（`ui.press`）观察它的效果。
- **本片的用例只断言「调用了起飞、没有预填」**：测试世界记到对该 change 的 `takeoff-gate.py` 调用即可。起飞后续成不成功不在本片断言范围；S4 合回后被拒会进入待命，那由 final 全量验证。

## 做什么（design D7、D8；spec `flight-band-takeoff`）

### `template/plugins/flight/hooks/io.ts`
`stoppedNow`（第 48 行）：同一 attempt 先看 land，再看 halt（两行顺序对调），并改注释。

### `template/plugins/flight/hooks/register.tsx`
1. **显示规则**（`evaluate`，第 163 行起）按 spec 的表：
   - 停飞判定改为「`stoppedNow` 为 halt，且该 attempt 最后一条 halt 的 kind 不是 abort」。需要 halt 的 kind 时，读一次账本：已有的 `ledger.py show` 调用可以复用，`isAlreadyApproved` 的读法可参照；
   - 新增 `takeoff` 模式：最近一次 approve 晚于最近一次 takeoff（或从未起飞），且指纹相同。这正是 `isAlreadyApproved` 现在的判定（`last === item.fp`），可直接复用；
   - 「批准起飞」「起飞」的说明行：未提交工件数 N，用 `git -C <worktree> status --porcelain --untracked-files=all`，再交给 `land.ts` 的 `classifyDirty`（纯函数，可以 import），scenarioFiles 读该 change 的 `slices.json`。
2. **按键**（`ui.press`，第 395 行起）：
   - 正则加上 `takeoff`；`PRESS_KEY` 同步；
   - `approve`：写 approve 后，在后台 `takeoffNow([change, '授权提交'])`。原来「指纹相同即 duplicate → 预填」的分支，按新规则此时应显示为 `takeoff`，按下走第二条；
   - `takeoff`：不写 approve，后台 `takeoffNow([change, '授权提交'])`；
   - `replan` / `resume`：照旧 `startResume`；
   - 起飞回复首行：`$.ui.toast` + `notifyQuietly`；
   - 删掉 `prefillApply` 及其调用。
3. **续飞依赖**（`depsOf`，第 279 行起）：`takeoff: (args, opts) => takeoffNow(args, opts)`。删掉现在的预填实现与那条 ceiling 注释。
4. **顺带修（LOW，无 scenario）**：
   - `toast: text => { try { $.ui.toast(text) } catch { /* 同 notifyQuietly */ } }`：同步抛错也吞掉；
   - `stopLive` 里按 `$.tool.call` 结果的 `isError` 判断是否停成功（参照 `orchestrator.tsx` 的 `taskStop`）；
   - 按键处理里那条「不预填，直接后台续飞」的注释照实改。
5. **渲染**：`LABEL` 加 `takeoff: '起飞'`。说明行按 mode 显示：replan 照旧；approve / takeoff 显示上面的工件数句子。
