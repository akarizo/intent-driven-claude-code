## 做什么（design D2、D4、D9）

### `template/.claude/hooks/timeline.py`
- **删除 `record` 子命令**与 `record()` 函数。
- **新增 `render --change-dir D`**：形状见 `slices/_interfaces.md`，格式见 design D2。
  - 读账本用 `ledger.read_events(change_dir)`。
  - gate-report 的表头、行格式、天花板表照搬 `slice-gate.py` 起点版本里的 `append_report`、`record_ceilings`、`ceiling_rows_from_json`。S1 会在 `slice-gate.py` 里删掉它们，本片不碰 `slice-gate.py`，把需要的部分复制进 `timeline.py`。
  - 写文件前先把全部内容算好，避免写一半。
- **`report` 改为两种模式**：
  - 账本里有 takeoff：账本模式，口径与输出行见 design D2；`timeline.md` 不存在也照常输出。
  - 否则（含账本读不出）：沿用现有 `timeline.md` 口径。
  - 「批准 → PR 打开」在账本模式下取第一条 ship；兼容模式照旧（ship 优先，否则 pr-open 行）。
- 文件头的用法注释同步。

### `template/.claude/hooks/ledger.py`
- 事件表增加 `diag`：必填 `attempt`（整数）、`where`（非空字符串）、`error`（字符串）。校验写法与其他事件一致。
- `events` 子命令随之列出 `diag`。

### `template/.claude/hooks/test-evidence.py`
- 删掉读 `.openspec-slice` 的逻辑。
- git toplevel 的当前分支以 `flight/` 开头时不写 `evidence.log`。取分支：`git symbolic-ref --short -q HEAD`，失败按非飞行处理。

### 测试
- **`tests/test_evidence_timeline.py`**：
  - `test_timeline_record_appends`：record 已删，删掉这个用例；「record 不存在」由 report-reads-ledger 覆盖。
  - `test_evidence_skips_ledger_marked_slice`、`test_test_evidence_skips_slice_worktrees`：按「分支 `flight/` 开头」改写，或被新 scenario 覆盖后删掉。
  - `test_red_count_from_ledger` 等 report 用例：按账本模式的新输出调整断言，保持原意。
  - `test_stop_gate_is_noop` 不动。
- **`tests/test_ship_verdict.py`**：`test_judges_know_ship_event` 的 report 现在按账本计算批准时间。给它的账本补一条 10:00:00 的 approve 事件，保持「批准 → PR 打开：30.0 min」这条断言。
