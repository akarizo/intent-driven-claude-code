## 做什么（`slice-gate.py`）
1. `_pool_dir(root)`：`git rev-parse --git-common-dir`（相对路径时相对 root 解析成绝对路径），加上 `/flight-baseline-pool`。
2. `_pool_write(root, entry)`：
   - entry 含 `change`、`commit`、`at`、`ok`、`cmd_key`、`snapshot`、`test`；
   - 按需建目录，文件名 `<at 去掉符号>-<change>-<commit 前 12 位>.json`，先写同目录下的临时文件再 `os.replace`；
   - 写完按 at（读不出时按文件名）保留最新 30 个，删掉更旧的；删除时遇到 ENOENT 忽略；
   - 任何 OSError 都只加一条警告，不影响基线结论。
3. `_pool_candidates(root, key, limit=10)`：读池里 `cmd_key == key` 的条目，按 at 由新到旧取前 limit 个。坏 JSON 跳过。
4. `cmd_baseline`：
   - 候选列表 = 本 change 旧基线（S1 已有）+ `_pool_candidates`。
   - 池候选的 `change` 与本 change 不同时，`_delta` 传 `same_change=False`；verify 全部重跑（本 change 没有上一次的记录）；`full_suite_sec` 为 None 时写候选的 `test.sec`（S1 已有这条规则）。
   - 只有 `mode == "full"`、`bl.ok`、且 `test.exit == 0` 或有 `test.failed` 时，才 `_pool_write`。
5. 文件头注释写明基线池的位置与保留规则。
