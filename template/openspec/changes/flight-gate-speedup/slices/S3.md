# S3 · 新引擎：有计划切片 blocked 时评审收齐后停飞

先读 `design.md` 的 D4。

## 做什么
`template/plugins/flight/hooks/core.ts` 的 `next()` → `closing()`：

1. 在 `closing()` 开头：`const stuck = plan.waves.flat().filter(s => blockedNow(s))`。
2. 非空 → 返回 `[{ kind: 'halt', reason }]`，不再往下走（不派修复、不返回 final）。
   - `reason`：「切片 blocked：S1（<原因首行>）、S3（<原因首行>）；未派修复、未跑 final。修好后重发 /opsx-apply <change> 续飞，只重派这些切片」。
   - change 名取 `takeoff.change`；拿不到就省略这一段。
3. `review:<S>` 与 `fix` 不在 `plan.waves` 里，天然不受影响；不要改 `reviewActions`、`firstDispatch` 等其余逻辑。
4. 续飞（新 attempt 只重派上一 attempt blocked 的切片）是现有行为：补一个 TS 测试覆盖，不改代码。
