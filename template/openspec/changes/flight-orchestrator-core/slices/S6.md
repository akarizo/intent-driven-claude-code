# S6 · 合回、冲突交接与快进、findings 校验、落地收口的机械过程

## 做什么
新建 `template/plugins/flight/hooks/land.ts`：只依赖 S2 的 `Io` 接口与类型（不 import `claude-code` 运行时值，不直接调用 `$`），测试用假 `Io` 记录调用。签名写死（S7 / S8 调用）：
```ts
import type { Finding, Flight, GateJson, Io } from './core'

export const RECORD_FILES = ['timeline.md', 'gate-report.md', 'evidence.log', 'slices/_interfaces.md']   // 相对 change 目录

/** 在 change worktree 里：提交飞行记录 → merge --no-ff → record --json → 刷新接口摘要 */
export async function mergeSlice(io: Io, f: Flight, slice: string, gate: GateJson, owns: readonly string[]):
  Promise<{ ok: true; commit: string } | { ok: false; conflicts: string[]; failed: string[] }>
/** 冲突时：merge --abort；建 <mainTree>/.claude/worktrees/flight-<change>-<S>-resolve（分支 flight/<change>/<S>-resolve，基于 f.branch）并在其中重做合并 */
export async function prepareResolve(io: Io, f: Flight, slice: string): Promise<{ path: string; conflicts: string[] } | { error: string }>
/** 解冲突完成：无未合并文件且 HEAD 有两个父 → change worktree 里 merge --ff-only flight/<change>/<S>-resolve；之后同 mergeSlice 的 record 与接口摘要 */
export async function finishResolve(io: Io, f: Flight, slice: string, gate: GateJson, owns: readonly string[]): Promise<{ ok: true; commit: string } | { ok: false; failed: string[] }>
/** 合回修复：提交飞行记录 → merge --no-ff flight/<change>/fix -m "integrate: fix" → timeline.py record fix */
export async function mergeFix(io: Io, f: Flight, note: string): Promise<{ ok: true; commit: string } | { ok: false; failed: string[] }>
export function validateFindings(input: unknown): { ok: true; findings: Finding[] } | { ok: false; error: string }
/** 落地收口：review-findings.json → 勾选 tasks.md → timeline apply-done → 收口提交 → slice-gate.py ship */
export async function closeout(io: Io, f: Flight, lists: { blocked: { slice: string; kind: 'gate' | 'infra'; reason: string }[]; blocking: Finding[]; deferred: Finding[]; fix: { ok: boolean; commit: string } | null }, merged: readonly string[]):
  Promise<{ verdict: 'ready' | 'draft'; reasons: string }>
```

## 细节（spec flight-integration）
- **路径**：change 目录 = `${f.changeTree}/${f.changeDir}`；判定器 = `python3 ${f.hooksDir}/<name>.py`；git 一律 `git -C <worktree> ...`。
- **提交飞行记录**：`git status --porcelain -- <RECORD_FILES 的绝对路径>` 有输出才 `git add` 这几个文件并 `git commit -m "chore(flight): 记录"`。change 目录之外的未提交改动不碰。
- **冲突判定**：`git merge` 退出非 0 后，`git diff --name-only --diff-filter=U` 得到未合并文件；为空则按非冲突失败返回（failed 含 git stderr 首行）。冲突时 failed 里每个文件写成 `conflict: <文件>`（S2 的状态机靠这个前缀派发解冲突 agent）。
- **record**：`slice-gate.py record --change-dir <changeDir> --json <JSON.stringify(gate)>`，cwd 为 change worktree。
- **接口摘要**：对 owns 里存在的、非测试（不在 tests/ 下，文件名不含 test）、非 `.md` 的文件，取匹配 `^(def |class |export |func |pub )` 的行。写进 `slices/_interfaces.md` 的 `## <S>` 一节：已有该节则整节替换，否则追加。
- **finishResolve 的检查**：
  - `git -C <resolve> diff --name-only --diff-filter=U` 为空；
  - `git -C <resolve> rev-list --parents -n 1 HEAD` 有 3 个字段。
  
  任一不满足 → `{ ok: false }`，且不运行 `--ff-only`。
- **validateFindings**：输入必须是 `{ findings: [...] }`；逐项校验，错误信息写成「第 N 项的 <字段> …」（N 从 1 起）。
- **closeout**：
  - `review-findings.json` 写 `{ blocked, blocking, deferred, fix }`，2 空格缩进；
  - tasks.md 里把 merged 中每个 S 的行首 `- [ ] <S> ` 改为 `- [x] <S> `；
  - 运行 `timeline.py record apply-done --change-dir <changeDir> --note "blocked=<n> blocking=<n>"`；
  - add 飞行记录、review-findings.json、tasks.md 后提交 `chore(flight): 收口`；
  - 运行 `slice-gate.py ship --change-dir <changeDir>`：退出 0 为 ready、1 为 draft，reasons 取 stdout。
