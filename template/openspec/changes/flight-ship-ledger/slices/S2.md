## 做什么（`template/plugins/flight/hooks/core.ts`，design D1 / D2）

### 类型
- `Action` 按 `slices/_interfaces.md` 的约定改：
  - reviewer 动作增加可选的 `mode`、`base`、`prior`；
  - fixer 动作增加可选的 `slice`，缺省视为 `'fix'`。
- `ev.dispatch` 的参数类型增加可选的 `commit?: string`。

### `closing()`
- 前半段（blocked 切片停飞、切片级修复 `fix`）照旧。只改一处：切片级修复取的 findings 只来自切片评审，不含 slice 为 `whole` 或 `whole-r<k>` 的 review 事件。`reviewFindings` 可以加参数，也可以另写过滤函数。
- final 那一段改为 design D2 的完整判定：
  1. 本 attempt 没有 final → 动作 `final`；最新 final 红 → 停飞（原文案不变）。
  2. 本 attempt 里，slice 匹配 `^fix-r\d+$` 且 ok 的 merge 事件，seq 晚于最新 final → 动作 `final`。
  3. 记 `k` = 本 attempt 已合回（ok merge）的修复轮数，当前评审轮 `R` = `k === 0 ? 'whole' : 'whole-r' + k`。
  4. 本 attempt 没有 `R` 的 review 事件时：
     - 有 blocked `review:R` → `land`；
     - 没有 `R` 的 reviewer 派发 → 派发评审员：
       - `k === 0`：`{ kind: 'dispatch', role: 'reviewer', slice: 'whole', mode: 'whole', commit: <最新 final 的 commit>, prior: <切片评审的 CRITICAL/HIGH> }`；
       - `k > 0`：`{ ..., slice: R, mode: 'followup', base: <上一轮评审员 dispatch 的 commit 字段>, commit: <最新 final 的 commit>, prior: <上一轮 review 的 CRITICAL/HIGH> }`。上一轮的 slice 为 `k === 1 ? 'whole' : 'whole-r' + (k - 1)`。
     - 已派发、该 agent 还没 ended → `[]`；
     - 已 ended → blocked `review:R`（infra），原因 `评审未返回：<agent>`，与切片评审一致。
  5. `R` 的最新 review 没有 CRITICAL/HIGH，或 `k >= 2` → `land`。
  6. 否则 `F = 'fix-r' + (k + 1)`：
     - 本 attempt 有 blocked `F` → `land`；
     - 没有 `F` 的修复体派发 → `{ kind: 'dispatch', role: 'fixer', slice: F, findings: <R 的 CRITICAL/HIGH> }`；
     - 修复体还没 ended → `[]`；
     - 结束后，若它 ended 之后已有 `F` 的 merge 事件（失败）→ blocked `F`（infra，「修复合回失败：…」）；
     - 收口门禁最后一条绿 → `{ kind: 'merge', slice: F, via: 'fix' }`；
     - 否则 → blocked `F`（gate）。
     - 以上写法与现有 `fix` 分支一致。
- 轮次与评审只看本 attempt（`ofA`）。现有切片评审、切片级修复的「跨 attempt 计入」口径不动。

### 面板
- `FlightSummary` 增加 `whole: string`，取值：
  - `未开始`：本 attempt 没有派过 whole；
  - `进行中`：当前最新一轮已派、没有 review、没有 blocked；
  - `未返回`：最新一轮有 blocked `review:<slice>`；
  - `第 n 轮 x 条（CRITICAL/HIGH y）`：取最新一轮 review。`n` 为轮次序号加 1，即 `whole` 为第 1 轮、`whole-r1` 为第 2 轮。
- `summaryLines` 末行改为 `修复 ${fix} · final ${final} · 全量评审 ${whole}`。
- `fix` 字段的「未派 / 无需」判断同样只看切片评审。
