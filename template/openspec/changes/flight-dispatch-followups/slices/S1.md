## 做什么（design D2–D5）

### `template/plugins/flight/hooks/armed.ts`
1. `export const WAKE_FOOTER = '这一轮只回复「收到」，不要做别的，也不要发 /opsx-apply。'`，`wakePrompt` 的第二行改用它。
2. `Arm` 加 `missedTurn: boolean`（`armOf` 置 false，`beforeRetry` 置回 false）与 `submittedAt?: number`。
3. `afterMissedTurn(arm)`：`arm.awaitingWake || arm.awaitingModel` 时返回 `{ ...arm, awaitingWake: false, awaitingModel: false, missedTurn: true }`，否则原样返回。
4. `nextStep`：在 `main-turn && awaitingWake → retry` 那条之后加一条：`(tick || timer) && arm.missedTurn` 时，`awaitingWake ? { do: 'wait' } : { do: 'wake', text: wakePrompt(arm) }`。任何类别都适用。

### `template/plugins/flight/hooks/orchestrator.tsx`
5. **排队计入「正在飞」**：
   - 模块级 `queued: Map<string, number>`；
   - `drive()` 入队前 `queued.set(name, n + 1)`，那次 drive 的 Promise 结束（含异常）时减一，减到 0 就删除；
   - 「正在飞」判据加上 `(queued.get(name) ?? 0) > 0`。
6. **错过的那一轮**：
   - 模块级 `missedTurns: Set<string>`；
   - `advanceArm` 撞锁且 `event.kind === 'main-turn'` 时 `missedTurns.add(change)`；
   - `advanceArm` 与 `takeoffArmed` 释放锁之后（`finally` 里），若 `missedTurns.has(change)`：先删除，再读当前待命，仍满足 `awaitingWake || awaitingModel` 就 `putArm($, afterMissedTurn(arm))`；
   - 读写失败只记一行，不抛。
7. **abort 措辞**：
   - `armBusy` 改为 `Map<string, 'auto' | 'manual'>`：`advanceArm` 记 `auto`，`takeoffArmed` 记 `manual`；其余 `.has` / `.delete` 照旧；
   - abort 撞锁时，`manual` 回复「flight：<change> 正在起飞，结束后再 /flight abort」，`auto` 照旧。
8. **看门狗唤醒失败留日志**：`deferTriage` 的失败分支在通知之外加 `await ctxOf($).log(...)`，文本含 change 与「唤醒失败」。唤醒正文第二行改用 `WAKE_FOOTER`。
9. **类型**：删掉为 `submittedAt` 而写的 `as Arm` 与 `Arm & { submittedAt?: number }`，改为直接用 `Arm`。

### `template/plugins/flight/types/index.d.ts`
10. `FlightArmedItem` 加 `missedTurn: boolean`（注释：唤醒或交模型那一轮撞锁被错过，下一次 tick 补发唤醒）。

### pytest 残留（本片 owns）
